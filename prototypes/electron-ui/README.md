# Electron 界面原型

浏览器模式是独立的静态交互原型，不读取或保存真实配置，不执行网络登录、游戏启动、下载或系统注册。请勿输入真实凭据。

已增加可选的 [Electron 与 .NET 整合开发入口](../../frontend/README.md)，复用同一套页面。目前已接入设置、凭据管理、登录验证、游戏更新、共用启动链、三端公告与活动列表及内置浏览器入口，使用独立测试目录。真实游戏流程仍需验收。以下模拟交互说明均指普通浏览器模式。

从仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765/prototypes/electron-ui/`，也可以直接打开 index.html。

保留六个页面入口，重点评审游戏首页、三游戏区服布局、验证码与扫码提示、错误状态，以及每文件同一行刷新的下载百分比。其他页面为布局草案；界面语言选择后立即切换简体中文、繁體中文、日本語或 English。公告和账户均为示例。当前 1.0.0 运行逻辑及打包入口保持不变。

布局确认后已接入通信层，提取共用启动协调服务，并连接进度、取消及验证交互接口；其余功能继续逐步接入现有 .NET 服务。正式版本继续使用已校对的四语文案。

## 官方前端研究与服务器状态（2026-10-09）

已静态检查用户提供的官方 FfxivLauncherTC.exe，并沿公开 v1.txt 清单下载分析 Userjoy.Ffxiv.Browser.dll 与 Userjoy.Ffxiv.Launcher.dll。研究文件仅在 /tmp/ffxiv-official-research，不纳入仓库或发行包。

- 引导程序为 .NET Windows Forms；根据版本清单下载 Deflate 压缩组件，再动态加载托管程序集。
- Browser.dll 是原生组件，存在 WebView 环境创建符号及嵌入 HTML/JavaScript；网页使用 chrome.webview.hostObjects.ffxiv 与原生后端交互。由这些证据判断为 WebView2 路线，不是 Electron。
- Launcher.dll 通过 CreateCoreWebView 等原生导出创建网页视图，接收导航和新窗口事件。官方公告区域通过 iframe 加载远端公告页。
- 只能确认繁中官方的实现，尚无证据证明三端共用前端代码。不复制官方反编译代码、脚本或美术资源；以此研究网页与业务的职责划分。

公开来源：
- 官方组件清单：https://user-cdn.ffxiv.com.tw/launcher/ob/v1.txt
- 官方公告页：https://user-cdn.ffxiv.com.tw/news/251115/launcher_left.html
- 中国区服务器状态：https://ff.web.sdo.com/web8/index.html#/servers
- 繁中服务器状态：https://www.ffxiv.com.tw/web/worldstatus/index.aspx
- 国际区服务器状态：https://na.finalfantasyxiv.com/lodestone/worldstatus/

服务器状态按游戏区服打开官方页面，不新增状态拉取、解析、缓存或后端查询服务。中国区保留 `#/servers` 路由。静态原型使用浏览器新标签页；Electron 整合入口已复用已有内置浏览器及“用系统浏览器打开”功能，不使用 iframe 嵌入官网。国际区页面及资讯来源跟随账户 CDKey 版本与 EU 偏好语言设置。普通浏览器原型不连接游戏服务，但点击服务器状态会访问官方网页。

官方页面按钮顺序：游戏官网 → 服务器状态 → 官方商城 → 游戏时长充值（国际区为 Mog Station）。三端共用此布局。


## 当前交互预览

- 使用用户保存的 `background.png` 原样副本（`assets/background.png`），不套用调色滤镜；背景固定于视口，不受验证面板展开影响。
- 中文采用源流明体 TC Regular，日文采用源流明朝 PJP Regular，英文品牌标题及界面拉丁文字采用 Cinzel。输入框保留源流字体以便区分账户名的大小写，诊断日志使用等宽字体。字体随预览附带、离线加载；许可证为 `assets/GenRyu-OFL.txt` 和 `assets/Cinzel-OFL.txt`，下载来源与 SHA-256 记录在 `assets/font-sources.json`。源流官方：https://github.com/ButTaiwan/genryu-font ；Cinzel 官方字体包：https://github.com/google/fonts/tree/main/ofl/cinzel 。已移除预览不再使用的思源宋体字体文件。
- 使用已记录的暖银白主题，主按钮 `#F5E8D5`，高光 `#F7EFDC`。没有常驻“准备就绪”模块；日志以底部原生 details 控制透明浮层展开，下载同一文件只更新同一行。
- 标题试用双层衬线字标：`FFXIV` 与 `Super Launcher`，搭配暖银白渐变和原创双剑／盾／水晶纹饰（`assets/wordmark-crest.svg`）：双剑交叉于盾后，盾面包含分层边框与单颗切面水晶，水晶缩小至前一版的 80%，移除周围碎晶与装饰点。原有图标保持不变；纹饰使用独立 SVG，不复制官方徽标或职业图标。字标独立指定已附许可证的 Cinzel，所有界面语言沿用同一英文品牌字标，不随正文的语言字体切换；保留完整的无障碍名称。艺术字渐变和微光仅用于左上角品牌标题；栏目标题、导航、按钮、正文和日志均使用普通字体渲染，不添加文字渐变、描边、阴影或发光。
- 验证码、扫码与手机滑动验证提醒共用“开始游戏”下方的同一面板；可展开底部日志后，通过工具栏“交互演示”切换模拟状态。登录按钮：中国区演示扫码，其余区服未勾自动生成时演示 OTP。滑动操作在手机叨鱼 App 内完成，启动器仅展示通知、五位数验证码及等待状态，并提供取消登录；没有本地滑动条或确认完成按钮。预览固定使用 `12345` 示例码，不请求或提交真实验证码；正式接入时展示后端返回的验证码并等待后端结果，不将该验证码写入日志。
- 游戏区服选择恢复到“语言和区服”；右上角只显示并跳转。国际区 CDKey、EU 偏好语言、客户端语言已补回布局。设置仅保存在当前页面内存，后端行为仍以 1.0.0 为准。
- 凭据、Proton、插件、关于页面均为布局草案，未接入后端。不要输入真实密码、密钥或验证码。
- 本次用户明确要求打开交互页；后续仍需用户提出交互预览要求才打开。

验证面板采用固定预留空间，显隐不推动登录框、公告或日志。根据视口高度缩紧内边距和占位尺寸；空间极小时只滚动面板内容。桌面主内容区域由视口、导航及底部固定日志标题分配，日志浮层不参与主内容高度分配；窄窗口改为单列，但验证区域仍预留固定高度。

日志布局修正：从底部标题上方向上展开透明浮层，不占用主内容布局空间。登录名选择框、日志窗口及交互演示菜单共用透明背景与 3 px 背景模糊；仅模糊覆盖区域的背景，文字、按钮和边框保持清晰，不通过整体 `opacity` 淡化内容，也不使用全屏暗色遮罩。所有页面内的 `dialog`、`popover` 及下拉列表的展开面板均沿用此规则。日志浮层总高度最多为 300 px 或视口高度的 38%（取较小值），正文最多为 220 px 或视口高度的 28%；超出后仅在日志内部滚动。新增、清空、长文本换行及展开／收起均不改变主界面、登录框或验证区的位置和尺寸。

滚动条统一采用暖银白金属滑块，与“登录并启动”按钮共用 `--primary: #F5E8D5` 底色，可见宽度为 10 px，保持 18 px 的原有滚动条占位。滑块保留柔和分面高光、深浅边框和中央菱形镶饰，没有中轴刻线；轨道只保留低对比半透明双边线。横向滑块沿用同一图案并旋转方向。首尾箭镞保持原有尺寸，原创 SVG 包含双侧镂空三角刃、中脊和短尾柄，以暖银灰搭配主题淡金高光 `#F7EFDC`；悬停只提亮图案本身，不绘制矩形底色。`scrollbars.css` 集中定义滚动条样式，`assets/scroll-arrows.svg` 共用四方向箭镞，`assets/scroll-grip.svg` 共用横纵滑块镶饰。保留浏览器原生滚动、拖动、滚轮、键盘及按住箭头连续滚动，不引入额外滚动控件或脚本；Chromium／Electron 使用完整样式，其他浏览器使用细滚动条回退。

日志展开图标、交互演示菜单箭头、所有复选框选中标记及单选下拉列表箭头共用简洁的尖角图案 `assets/control-chevron.svg`，与滚动条的装饰箭镞分开。展开日志或菜单时箭头翻转；复选框选中时显示深色标记及主题浅色底，未选中时为空框，禁用时降低对比。控件保留原生标签、键盘操作和焦点轮廓，下拉列表预留箭头空间，短窗口也不会挤压文字。高对比模式下复选框与下拉列表恢复系统绘制，浮层使用系统背景色以维持可读性。

下拉列表通过 Chromium 的 `appearance: base-select` 与 `::picker(select)` 定制原生顶层面板，背景透明并使用共用的 3 px 模糊。选项跟随界面字体，当前项在文字左侧显示独立的切面水晶标记 `assets/selection-crystal.svg`，沿用原有暖银白配色。所有选项都预留同宽的 12 px 标记栏及 12 px 间距；未选中项仅隐藏水晶，不收回占位，确保切换选择时上下文字始终对齐。悬停和键盘焦点使用淡色描边。列表高度最多为 280 px 或视口高度的 40%（取较小值），长列表内部滚动，浏览器负责边缘避让。保留原有 `select` / `option`、值、禁用状态、键盘选择及 `change` 事件，不复制选项、不增加镜像控件或同步脚本。旧浏览器回退到原生列表；当前附带的 Electron 44.5.1 使用可定制列表。

公告与活动资讯按内容高度向上紧凑排列，不再平均拉伸填满左栏。四个官方入口紧接资讯列表，置于背景图区域内；窗口较小时由整个页面统一滚动，公告、资讯和登录卡内部不另设滚动条。底部只保留日志栏，预览说明及交互演示入口合并到日志浮层工具栏；选择验证演示后自动收起日志，以便查看验证面板。

独立浏览器原型画布的整体高度最多为背景图按宽度显示的高度加 68 px；超出画布的浏览器空间以独立底色显示。真实桌面／整合页面不使用这项高度限制，始终填满窗口，背景等比例覆盖，避免普通窗口下日志底部出现黑色空白。日志浮层和验证面板保持原有显隐行为，背景不随列表滚动。

相邻设置按钮组之间保留 16 px 纵向间距；插件页面未接入列表时，上方的两项更新按钮与下方三项操作也不会紧贴。长文案仍在原高度内换行。

## 四语言字体预览

“语言和区服”中的界面语言依次为简体中文、繁體中文、日本語、English。选择后立即更新导航、六个页面、示例公告与活动、扫码／手动验证码／手机滑动提醒、错误提示和日志操作；只保存在本次预览内存中，刷新页面恢复默认。游戏区服、CDKey 与客户端语言仍是独立选项，切换界面语言不改变其选择。账户、密码、密钥的输入值不参与翻译，诊断日志内容保留生成时的语言。

`locales.js` 集中保存预览文案，沿用已校对的正式版标签，另补齐原型说明与示例内容；`i18n.js` 只更新展示文本、提示和无障碍标签，不读写配置或后端。所有语言共用同一套页面模板与交互。正式前端接入时再统一现有本地化服务。

英文和日文的长按钮文案与顶部六个选项卡在固定高度内换成两行，不因翻译变长而增高按钮或单独增加导航排数。三端共用的登录卡将“检查并更新游戏”置于左侧、“登录并启动”置于右侧，DOM 与键盘顺序一致；避免左侧大区下拉列表的文字直接叠在浅色登录按钮上。国际区登录卡移除 Steam 勾选项下的长说明，仅保留勾选项。短画布按可用高度收紧登录卡间距，验证区按内容增高，超出窗口时与首页共用页面滚动。

验证码输入框聚焦时仅改变自身边框颜色，不使用外置白色轮廓，避免在输入框上下产生额外白条。

## 插件页面的整合模式

通过 Electron 整合入口打开时，插件页面现已连接共用 .NET 服务：读取／刷新／保存启用状态、手动更新 Dalamud、检查并选择插件更新，以及选择来源与目标区服同步指定类别。勾选后立即保存，失败恢复已读取状态；刷新直接读取对应数据并清除提示；后台任务期间禁用编辑并提供取消，失败后恢复操作。插件名称按原文展示，页面提示和弹窗提供四种语言。普通浏览器原型仍为模拟布局；离线验证使用独立的合成资料页，详见 [frontend/README.md](../../frontend/README.md)。

完整 Electron 接入已覆盖首次设置、兼容性工具、超域传送、窗口状态、关于和更新。繁中区网页验证采用与手动验证码相同的页面区域，隔离网页在后台认证完成前保留会话。诊断路径在所有页面紧贴底部日志栏上方显示。运行包不加载模拟后端，完整说明见 [frontend/README.md](../../frontend/README.md)。

整合模式下日志保留未变化的文字节点，支持鼠标选择及复制；选择期间暂缓内容替换。任务结束后停止轮询，隐藏窗口减少后台轮询和重绘；验证网页初始化有超时及即时取消，认证结束后释放。详细边界和测试范围见前端开发说明。

1.1.5：空选择框高度固定，四语言顶部选项卡使用同一宽度分配；按钮下方说明保留 16 px 间距。整合模式下插件管理右侧增加仓库管理，较窄窗口自动排列到下方，原左侧内容保持不变。
