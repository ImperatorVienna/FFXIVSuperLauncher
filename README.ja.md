# FFXIV Super Launcher

**Linux** 向けの、**Proton** を使用してゲームを実行するコミュニティ版 FINAL FANTASY XIV（以下 FFXIV）ランチャーです。**中国版、繁体字中国語版、グローバル版**のゲームクライアントに対応します。

本プロジェクトは **[ImperatorVienna](https://github.com/ImperatorVienna)** が保守し、[XIVLauncher](https://github.com/goatcorp/FFXIVQuickLauncher)、[XIVLauncherCN](https://github.com/ottercorp/FFXIVQuickLauncher)、[XIVLauncherCN (Soil)](https://github.com/AtmoOmen/FFXIVQuickLauncher) のソースコードと知見を基に開発を継続しています。また、繁体字中国語版のログインプロトコルと機能設計では [XIVTCLauncher](https://github.com/cycleapple/XIVTCLauncher) を参考にしています。独立して保守されるコミュニティの派生プロジェクトであり、Square Enix、Shengqu Games、USERJOY の公式リリースではなく、上記の上流プロジェクトによる保守や推奨も受けていません。原作者の著作権表示とライセンス通知は保持しています。

> **対応プラットフォーム：x86_64 Linux。** リリースファイルとリリースノートは [Releases](https://github.com/ImperatorVienna/FFXIVSuperLauncher/releases) から取得できます。1.0.0 のチェックサムファイルは [release-materials/1.0.0](release-materials/1.0.0) にあります。

内蔵ブラウザーは公式ページと Web 認証で共用し、各ゲームリージョンのログインモジュールから独立しています。

## 機能

- **3 つのゲームリージョン**：グラフィカルなフロントエンドと Proton の起動処理を共用し、クライアントのディレクトリ、アカウント認証情報、Dalamud、プラグインのデータを個別に管理します。
- **Proton 対応**：システムと Steam ライブラリにインストールされたバージョンを検索し、手動でのパス指定にも対応します。Arch Linux ベースの CachyOS / proton-cachyos-slr 環境で実機テスト済みです。
- **アカウント管理**：ゲームリージョンごとにアカウントを追加・選択・編集・削除できます。認証情報はローカルの平文ファイルに保存できます。
- **認証コード**：繁体字中国語版とグローバル版で、認証コードの手動入力とローカルでの TOTP 自動生成に対応します。グローバル版では、アカウントで OTP を有効にしている場合のみ入力が必要です。
- **ゲーム更新**：対応するゲームリージョンのクライアントパッチを確認・インストールします。ゲームを起動せず、更新のみ行うこともできます。
- **Dalamud とプラグイン**：Dalamud は任意で有効にできます。ゲームに入らずにプラグインの有効・無効を管理し、Dalamud とプラグインの更新を確認できます。
- **ゲームリージョン間の同期**：「Dalamud 設定を同期」「インストール済みプラグインを同期」「プラグイン設定を同期」で選択した種類を個別に同期します。同期元のゲームリージョンと 1 つ以上の同期先を選択し、「選択したゲームリージョンに同期」をクリックすると、選択した同期先の対応する内容のみを上書きします。
- **Steam 連携**：グローバル版の Steam アカウントによるログインに対応します。Steam compatibility tool として手動登録し、Steam からランチャーを開いてプレイ時間を記録できます。
- **画面とお知らせ**：简体中文、繁體中文、日本語、English に対応します。対応するゲームリージョンの公式イベントとお知らせを表示し、公式ページへのリンクを提供します。
- **中国版のデータセンター間移動**：移動申請の送信、履歴の照会、元のデータセンターへの帰還に対応し、完了後にゲームを起動できます。

サードパーティー製ランチャー、Dalamud、プラグインを使用する前に、ゲームの関連利用規約を読み、使用に伴うリスクをご自身で判断してください。Dalamud は既定で無効です。本プロジェクトはアカウントの安全性やプラグインの利用可能性を保証しません。

## 特長

- **Linux 専用に開発**：x86_64 Linux のみを保守し、Windows、macOS、ARM、32 ビット x86 版は提供しません。AppImage 形式で配布し、イミュータブルなシステムを含む Linux デスクトップへの導入を容易にします。具体的な互換性についてはリリースノートを参照してください。
- **Proton による互換性確保**：XIVLauncher と XIVLauncherCN に同梱されていた Wine + DXVK 方式を削除し、インストール済みの Proton を呼び出す方式に変更しました。インストール済みの Proton を自動検出し、CachyOS の proton-cachyos-slr で実機検証済みです。
- **各ゲームリージョンの一元管理**：1 つのランチャーで中国版、繁体字中国語版、グローバル版のログインを切り替え、アカウント、クライアント、プラグインのデータを個別に保存します。各ゲームリージョンの Dalamud 本体は必要に応じてダウンロードします。実行パッケージには共用または事前配置された補助コンポーネントが含まれる場合があります。
- **ゲーム外でのプラグイン管理**：ゲームに入らずにプラグインの有効・無効を変更し、更新するプラグインを選択し、ゲームリージョン間で設定を同期できます。
- **認証情報の管理**：ゲームリージョンごとにアカウントのログイン認証情報を管理し、ローカルの平文保存とローカル TOTP 生成に対応します。
- **グローバル版で Steam 版の既存 pfx を再利用**：公式ランチャーから FFXIV Super Launcher に切り替えた後も、元の pfx にあるローカルのゲーム設定とキャラクター設定ファイルを引き継げます（サーバーに保存されたキャラクターの進行状況には関係しません）。
- **繁体字中国語版の Dalamud 注入への対応**：Linux／Proton 環境向けに注入処理を調整し、グローバル版と同じ entrypoint 経路を使用して、元の繁体字中国語版の注入処理にあった ArgFixer をスキップします。キャラクターへのログイン、プラグインのインストールと実行を実機で検証済みです。
- **中国版の Dalamud ブランチ選択**：Soil が使用する Dalamud-DailyRoutines ブランチと更新元を採用し、ottercorp ブランチのプラグインブラックリスト方針は引き継ぎません。これは、すべてのプラグインに互換性があることや、ゲームの利用規約の対象外であることを意味しません。

## インストールと初回利用

### 動作条件

- x86_64 Linux のグラフィカルデスクトップ。
- インストール済みの Proton と、そのバージョンに必要な Steam Linux Runtime。具体的な依存関係は、選択した Proton の説明を参照してください。
- 対応するゲームリージョンの完全なクライアント。**本プロジェクトには、空のフォルダーにゲームクライアント全体をダウンロードする機能はありません。**
- 正常に動作するグラフィックスドライバーと、選択した Proton に必要な Vulkan サポート。

実行パッケージには .NET と Electron（Chromium と Node.js を含む）の実行コンポーネントを内蔵しており、.NET SDK、Electron、ブラウザーを別途インストールする必要はありません。他のディストリビューションの依存関係と検証状況は、各リリースノートを参照してください。CachyOS で動作することは、すべてのディストリビューションやサンドボックス環境でテスト済みであることを意味しません。

### AppImage

[Releases](https://github.com/ImperatorVienna/FFXIVSuperLauncher/releases) から x86_64 AppImage をダウンロードし、実行権限を付与して起動してください。任意の書き込み可能なディレクトリに配置できます。配布する実行パッケージは AppImage のみです。

初回設定ウィザードで表示言語、ゲームリージョン、Steam / Proton のディレクトリ、Dalamud を有効にするかどうかを設定します。

その後、「言語とリージョン」でクライアントのディレクトリを設定してください。`game` サブディレクトリを含むゲームのインストール先を選択します。グローバル版には、完全な `boot` サブディレクトリも必要です。

「ログイン認証情報の管理」の「アカウントを追加」で認証情報を入力し、「保存」をクリックしてください。「ゲーム」ページに戻り、「ログイン名を選択」でアカウントを選択してから、「ログインして起動」をクリックします。中国版の新規アカウントはログイン名のみ入力し、初回ログイン時に QR コードを読み取ります。成功するとクイックログイン認証情報が自動保存されます。

### 表示言語とグローバル版の言語設定

「言語とリージョン」ページで設定します。

- **ランチャーの表示言語**：選択後、横の「適用」をクリックし、案内に従ってランチャーを再起動すると、すべてのページに適用されます。
- **グローバル版クライアントの言語**：グローバル版を選択した場合のみ表示され、日本語、English、Français、Deutsch から選択できます。横の「適用」をクリックすると、次回のゲーム起動時に反映されます。他のゲームリージョンに切り替えても、この選択は消去されません。
- **アカウントの CDKey バージョン**：アカウントの実際のライセンスに合わせて JP、NA、EU を選択します。既定は NA です。対応する公式サイト、ストア、Mog Station、イベントとお知らせの取得元を選ぶ設定であり、アカウントのライセンスを変更するものではありません。
- **公式サイトとストアの優先言語**：CDKey バージョンが EU の場合のみ表示され、English(UK)、Français、Deutsch から選択できます。公式サイト、ストア、お知らせの言語を選ぶために使用します。これらの Web ページの設定は変更後に自動保存され、クライアント言語とは独立しています。

## Steam と Proton

### Steam ライセンスのアカウント

グローバル版アカウントの CDKey を Steam で購入した場合は、「CDKey は Steam で購入しました」を有効にし、ログイン前に Steam クライアントがサインイン済みで実行中であることを確認してください。

ランチャーは Steam アカウントのパスワードの入力や保存を要求しません（Steam は CDKey の所有権確認にのみ使用し、ゲームへのログインは引き続き Square Enix アカウントで行います）。

### Steam からランチャーを起動する

「互換性ツール設定」で「Steam compatibility tool として登録（いつでも解除可能）」を有効にすると、**FFXIV Super Launcher** を登録できます。Steam を再起動し、Steam ライブラリの FFXIV のプロパティで、この compatibility tool を選択してください。チェックを外すと登録を解除できます。

この機能は Steam からの起動入口を提供するもので、**Steam アカウント認証を有効にするものではありません**。アカウント認証は引き続き「CDKey は Steam で購入しました」で制御します。

この機能は固定の起動スクリプトを使用します。AppImage を手動で移動・改名した後は、一度起動すればパスが更新されます。ランチャーの自動更新後は、自動的に再起動してパスを更新するため、手動操作は不要です。

### compatibility environment / pfx

既定では、「互換性ツール設定」の「Proton データディレクトリ（ここに pfx を自動作成します。専用ディレクトリを推奨）」を使用します。グローバル版では「グローバル版で Steam の既存 pfx を使用」を有効にして、インストール済み Steam 版 FFXIV の既存環境と、その中のローカルゲーム設定を再利用できます。

このオプションが無効の場合、グローバル版も他の 2 つのゲームリージョンと共通の環境設定を使用します。Steam の既存環境を選択しても、プラグイン設定の移行や同期は行いません。

## 更新方法

ランチャーは起動するたびにバックグラウンドで安定版を確認します。「このアプリについて」のバージョン番号の横にある「更新を確認」も使用できます。更新チャンネルの選択機能はありません。AppImage の更新はユーザーの確認後に行い、全体のダウンロードが完了するとマニフェストの署名と SHA256 を検証してから元のファイルを置き換えます。更新ファイルは元のディレクトリに新しいバージョン番号を含むファイル名で保存し、旧版は `.previous` として保持します。Steam とアプリケーションメニューは `~/.local/share/xivlauncher-super/appimage-launcher` を経由して起動します。AppImage を手動で移動・改名した後は、一度ダブルクリックして起動し、パスを自動更新してください。その後も Steam やアプリケーションメニューから起動できます。複数のコピーがある場合は、最後に起動したファイルを使用します。更新前にゲームを終了してください。インストール後は、アプリケーションメニューへの登録に依存せず、新しい AppImage の絶対パスを使って新しい画面を自動的に開きます。アカウントと設定は独立して保存され、バックグラウンドの更新確認に失敗してもゲームへのログインを妨げません。

アプリケーションメニューの入口は AppImage の起動時に自動作成します。「このアプリについて」の「アプリケーションメニューに追加」は手動で入口を再作成するためのもので、通常は追加の操作は不要です。既定の入口ファイルは `~/.local/share/applications/xivlauncher-super.desktop` で、`XDG_DATA_HOME` に従います。AppImage を手動で移動・改名した後は、直接一度起動すれば記録が更新されます。

AppImage の起動時は、まず不足している既定の設定を作成し、固定の起動スクリプトとアプリケーションメニューの入口を順番に書き込んでから、更新を確認します。入口は「このアプリについて」から手動で再作成することもできます。設定完了後や入口の追加後は、利用可能なアプリケーションメニューのキャッシュをバックグラウンドで更新し、ターミナルウィンドウは開きません。キャッシュの更新に失敗してもランチャーは使用できます。メニューの入口は永続保存されたアイコンファイルの絶対パスを使用するため、AppImage のマウント解除後もアイコンを読み取れます。

| 操作 | 動作 |
| --- | --- |
| ログインして起動 | アカウント認証成功後にゲーム更新を確認し、Dalamud が有効ならその更新も確認してからゲームを起動 |
| ゲームの更新を確認して適用 | 現在のゲームリージョンのクライアントのみ更新。中国版・繁体字中国語版は事前ログイン不要。グローバル版はアカウント認証が必要ですが、ゲームは起動しません |
| Dalamud の更新を確認して適用 | 現在のゲームリージョンの Dalamud を手動確認 |
| プラグインの更新を確認して適用 | プラグインに記録された配布元リポジトリで更新を確認し、ユーザーがインストール対象を選択 |

Dalamud 更新時の接続がタイムアウトした場合は、既存の使用可能なバージョンで起動を続行するか、Dalamud を無効にして起動できます。無効化は設定に保存されるため、後で手動で有効に戻す必要があります。既存バージョンがない、または互換性がない場合、更新をスキップしても起動できるとは限りません。

上記の Dalamud とプラグインの 2 つの更新ボタンは「Dalamud とプラグイン」ページにあります。同じページには「プラグインの有効状態を再読み込み」と「プラグインの有効状態を適用」もあります。チェック状態の変更後は後者をクリックして保存してください。次回のゲーム起動時に反映されます。

ゲームリージョン間でプラグインを同期する前に、同期先の Dalamud API とプラグインのバージョンに互換性があることを確認してください。同期は選択した同期先のデータを上書きします。現時点では、繁体字中国語版のプラグイン DLL を他のゲームリージョンのバージョンと直接混用しないでください。

## 設定と認証情報

既定のデータディレクトリは次のとおりです。

```text
~/.local/share/xivlauncher-super/
├── ffxiv_cn/     # 中国版のデータ
├── ffxiv_tc/     # 繁体字中国語版のデータ
├── ffxiv/        # グローバル版のデータ
├── compatdata/  # pfx を含む既定の共通環境
└── logs/        # 診断ログ
```

プログラムは `XDG_DATA_HOME` に従います。Steam や Proton などの共通設定はランチャーのデータディレクトリに保存し、アカウントと Dalamud のデータはゲームリージョンごとに分離します。

認証情報は各ゲームリージョンのディレクトリ内の `credentials.json` に平文でのみ保存します。パスワード、2FA シークレット、クイックログイン認証情報は暗号化しません。ランチャーが作成する認証情報ファイルは、現在のユーザーのみ読み書き可能です。アップロードや共有はしないでください。

2FA シークレットは 6 桁の認証コードとは異なります。シークレットは認証コードを生成するためのもので、認証コードはその回のログイン時にのみ入力します。シークレット欄に 6 桁の認証コードを入力しないでください。

## フィードバック

問題や機能の提案は [GitHub Issues](https://github.com/ImperatorVienna/FFXIVSuperLauncher/issues) から送信してください。「このアプリについて」には「Discord に参加」ボタンを用意していますが、現在は無効です。コミュニティ開設後の更新で有効にします。

報告時は、できるだけ次の情報を含めてください。

- ランチャーのバージョン、Linux ディストリビューション、デスクトップ環境、Proton のバージョン。
- 現在のゲームリージョン、および直接起動か Steam compatibility tool 経由の起動か。
- 再現手順、期待する動作、実際の動作、エラー発生時刻。
- 必要なスクリーンショットや関連する診断ログ。

画面上のログは簡潔に表示します。診断ログの完全なパスは「このアプリについて」で確認できます。送信前にログとスクリーンショットを確認し、アカウント情報、ログインチケット、パスワード、2FA シークレット、QR コードなどの機密内容を削除してください。
