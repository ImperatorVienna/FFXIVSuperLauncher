# FFXIV Super Launcher

**Linux** 上で **Proton** を使ってゲームを実行する、コミュニティ版 FINAL FANTASY XIV（以下 FFXIV）ランチャーです。**中国版、繁体字中国語版、グローバル版**のゲームクライアントに対応しています。

**[ImperatorVienna](https://github.com/ImperatorVienna)** が保守する本プロジェクトは、[XIVLauncher](https://github.com/goatcorp/FFXIVQuickLauncher)、[XIVLauncherCN](https://github.com/ottercorp/FFXIVQuickLauncher)、[XIVLauncherCN (Soil)](https://github.com/AtmoOmen/FFXIVQuickLauncher) のソースコードと知見を基に開発を進め、繁体字中国語版のログインプロトコルと機能設計については [XIVTCLauncher](https://github.com/cycleapple/XIVTCLauncher) を参考にしています。独立して保守されるコミュニティ派生プロジェクトであり、Square Enix、Shengqu Games、USERJOY の公式リリースではありません。また、上記の上流プロジェクトが保守するものでも、推奨・承認するものでもありません。原著作者の著作権表示とライセンス通知を保持しています。

> **対応プラットフォーム：x86_64 Linux。** 配布ファイル、リリースノート、チェックサムは [Releases](https://github.com/ImperatorVienna/FFXIVSuperLauncher/releases) をご覧ください。

内蔵ブラウザーは公式ページとウェブ認証で共用し、各ゲームリージョンのログインモジュールから独立しています。

## 機能

- **3 つのゲームリージョン**：グラフィカルインターフェースと Proton の起動処理を共用し、クライアントディレクトリ、アカウント認証情報、Dalamud、プラグインデータは個別に管理します。
- **Proton 対応**：システムと Steam ライブラリにインストールされたバージョンを検索し、手動でのパス指定にも対応します。Arch Linux ベースの CachyOS / proton-cachyos-slr 環境で実機テストを行っています。
- **アカウント管理**：ゲームリージョンごとにアカウントを追加・選択・編集・削除できます。認証情報は ローカルの平文ファイルに保存できます。
- **認証コード**：繁体字中国語版とグローバル版では、手動入力とローカルでの TOTP 自動生成に対応します。グローバル版の OTP は、アカウントで有効にしている場合にのみ必要です。
- **ゲーム更新**：選択したゲームリージョンのクライアントパッチを確認して適用します。ゲームを起動せずに更新だけを行うこともできます。
- **Dalamud とプラグイン**：Dalamud は任意で有効にできます。ゲームに入らずにプラグインの有効・無効を管理し、Dalamud とプラグインの更新を確認できます。
- **リージョン間の同期**：「Dalamud 設定を同期」「インストール済みプラグインを同期」「プラグイン設定を同期」でカテゴリーごとに同期します。コピー元と 1 つ以上のコピー先を選び、「選択したゲームリージョンに同期」をクリックすると、選択したコピー先の該当データだけを上書きします。
- **Steam 連携**：グローバル版の Steam アカウント認証に対応します。Steam compatibility tool として手動登録し、Steam 経由でランチャーを開いてプレイ時間を記録することもできます。
- **表示言語とお知らせ**：简体中文、繁體中文、日本語、English に対応します。選択したゲームリージョンの公式イベントやお知らせを表示し、公式ページへのリンクを提供します。
- **中国版の超域転送**：転送申請、履歴確認、元のデータセンターへの帰還に対応し、完了後にゲームを起動することもできます。

サードパーティ製ランチャー、Dalamud、プラグインを使用する前に、ゲームの利用規約を確認し、リスクを判断してください。Dalamud は初期設定では無効です。本プロジェクトはアカウントの安全性やプラグインの利用可能性を保証しません。

## 本プロジェクトの特徴

- **Linux 専用**：保守対象は x86_64 Linux のみです。Windows、macOS、ARM、32 ビット x86 版は提供しません。AppImage 形式で配布し、イミュータブルなシステムを含む Linux デスクトップへの導入を容易にします。具体的な動作状況はリリースノートをご確認ください。
- **Proton を使用**：XIVLauncher と XIVLauncherCN の Wine + DXVK 同梱方式を廃止し、インストール済みの Proton を呼び出します。Proton を自動検出でき、CachyOS の proton-cachyos-slr で実機検証済みです。
- **ゲームリージョンの一元管理**：1 つのランチャーで中国版、繁体字中国語版、グローバル版を切り替え、アカウント、クライアント、プラグインデータを個別に保存します。各リージョンの Dalamud 本体は必要に応じてダウンロードします。実行パッケージには共通または事前同梱の補助コンポーネントが含まれる場合があります。
- **ゲーム外でプラグインを管理**：ゲームに入らずに有効・無効の変更、更新対象の選択、リージョン間の設定同期ができます。
- **認証情報の管理**：ゲームリージョンごとに認証情報を管理し、ローカルの平文保存、ローカル TOTP 生成に対応します。
- **グローバル版で Steam の既存 pfx を再利用**：公式ランチャーから FFXIV Super Launcher に移行しても、元の pfx 内にあるローカルのゲーム設定やキャラクター設定ファイルを引き継げます。サーバーに保存されたキャラクターの進行状況を移す機能ではありません。
- **繁体字中国語版の Dalamud 注入調整**：Linux／Proton 向けに注入処理を調整し、グローバル版と同じ entrypoint 経路を使用して、元の繁体字中国語版の注入処理にある ArgFixer をスキップします。キャラクターでのログインとプラグインのインストール・動作を実機で確認しています。
- **中国版 Dalamud のブランチ選択**：Soil が使用する Dalamud-DailyRoutines ブランチと更新元を採用し、ottercorp ブランチのプラグインブラックリスト方針は引き継ぎません。すべてのプラグインが動作することや、ゲーム利用規約の制約がなくなることを意味するものではありません。

## インストールと初回設定

### 動作要件

- x86_64 Linux のグラフィカルデスクトップ。
- インストール済みの Proton と、そのバージョンが必要とする Steam Linux Runtime。依存関係は選択した Proton の説明をご確認ください。
- 対象ゲームリージョンの完全なクライアント。**空のディレクトリにクライアント全体をダウンロードする機能はありません。**
- 正常に動作するグラフィックスドライバーと、選択した Proton が必要とする Vulkan サポート。

実行パッケージには .NET ランタイムが含まれるため、通常の利用に .NET SDK の別途インストールは不要です。他のディストリビューションの依存関係や検証状況はリリースノートをご確認ください。CachyOS で動作することは、すべてのディストリビューションやサンドボックス環境での検証を意味しません。

### AppImage

[Releases](https://github.com/ImperatorVienna/FFXIVSuperLauncher/releases) から x86_64 AppImage をダウンロードし、実行権限を付与して起動してください。任意の書き込み可能なディレクトリに保存できます。配布形式は AppImage のみです。


初回設定ウィザードで表示言語、ゲームリージョン、Steam / Proton のディレクトリ、Dalamud を有効にするかどうかを設定します。

続いて「言語とリージョン」でクライアントディレクトリを設定します。`game` サブフォルダーを含むゲームのインストール先を選択してください。グローバル版では完全な `boot` サブフォルダーも必要です。

「ログイン認証情報の管理」の「アカウントを追加」で認証情報を入力し、「保存」をクリックします。「ゲーム」に戻り、「ログイン名を選択」でアカウントを選択して「ログインして起動」をクリックしてください。中国版の新規アカウントはログイン名のみを入力し、初回ログイン時に QR コードをスキャンします。認証成功後、選択した保存方式でクイックログイン認証情報を保存します。

## Steam と Proton

### Steam ライセンスのアカウント

グローバル版アカウントの CDKey を Steam で購入した場合は「自分の CDKey は Steam で購入したものです」にチェックを入れ、ログイン前に Steam クライアントがログイン済みで起動していることを確認してください。

ランチャーは Steam のパスワードの入力や保存を求めません。Steam を通じて CDKey の所有権を確認するもので、ゲームへのログインには引き続き Square Enix アカウントを使用します。

### Steam から本ランチャーを起動

「互換性ツールの設定」の「Steam compatibility tool として登録（いつでも解除可能）」にチェックを入れると **FFXIV Super Launcher** を登録できます。Steam を再起動し、ライブラリ内の FFXIV のプロパティでこの compatibility tool を選択してください。チェックを外すと登録を解除できます。

この機能は Steam からの起動入口を提供するもので、**Steam アカウント認証を有効にするものではありません**。認証は引き続き「自分の CDKey は Steam で購入したものです」で指定します。

Steam は固定の起動スクリプトを使用します。AppImage を移動または名前変更した後は一度起動してください。旧方式の登録から移行する場合は一度再登録してください。

### compatibility environment / pfx

既定では「互換性ツールの設定」の「Proton データディレクトリ（ここに pfx を自動作成します。専用ディレクトリの使用を推奨）」を使用します。グローバル版では「グローバル版で Steam の既存 pfx を使用」にチェックを入れると、インストール済み Steam 版 FFXIV の既存環境と、その中のローカルゲーム設定を再利用できます。

チェックを入れない場合、グローバル版も他の 2 つのゲームリージョンと共通の環境設定を使用します。既存の Steam 環境の選択は、プラグイン設定の移行や同期を意味しません。

## 更新方法

起動時にバックグラウンドで安定版を確認します。「情報」のバージョン横にある「更新を確認」からも確認できます。更新チャンネルの選択はありません。AppImage はユーザーの確認後にファイル全体をダウンロードし、マニフェストの署名と SHA256 を検証してから置き換えます。新しい AppImage は同じディレクトリに新バージョン番号のファイル名で保存され、旧版は `.previous` として残ります。Steam とアプリケーションメニューは `~/.local/share/xivlauncher-super/appimage-launcher` を使用します。AppImage を移動または名前変更した後は一度起動してパスを更新してください。複数ある場合は最後に起動したファイルが使用されます。ゲームを終了してから更新してください。完了後はメニュー登録に依存せず、新しい AppImage の絶対パスから自動起動します。アカウントと設定は別に保存され、バックグラウンドの確認失敗はゲームログインを妨げません。

「情報」の「アプリケーションメニューに追加」を使用してください。移動または名前変更後は一度起動すればメニューの再作成は不要です。旧方式のエントリーから移行する場合は一度追加し直してください。

AppImage の起動時は、未作成の初期設定、固定起動スクリプト、メニュー項目の順に作成してから更新を確認します。「情報」から再作成することもできます。設定完了後とメニューへの追加後、利用可能なメニューキャッシュをバックグラウンドで更新します。ターミナルは開かず、失敗してもランチャーの使用を妨げません。メニュー項目は永続保存されたアイコンファイルの絶対パスを使用するため、AppImage のマウント解除後もアイコンを読み込めます。

| 操作 | 動作 |
| --- | --- |
| ログインして起動 | アカウント認証後にゲーム更新を確認し、Dalamud が有効ならその更新も確認してからゲームを起動します |
| ゲームの更新を確認して適用 | 選択したリージョンのゲームクライアントのみを更新します。中国版と繁体字中国語版はログイン不要です。グローバル版は認証が必要ですが、ゲームは起動しません |
| Dalamud の更新を確認して適用 | 選択したゲームリージョンの Dalamud を手動で確認します |
| プラグインの更新を確認して適用 | 各プラグインに記録された配布元リポジトリで更新を確認し、適用対象を選べます |

Dalamud の更新接続がタイムアウトした場合、利用可能な既存バージョンで続行するか、Dalamud を無効にして起動するかを選べます。無効化は設定に保存され、再び使うには手動で有効にする必要があります。ローカル版がない場合や対応していない場合、更新をスキップしても起動できるとは限りません。

Dalamud とプラグインの更新ボタンは「Dalamud とプラグイン」にあります。同じページには「プラグインの有効状態を再読み込み」と「プラグインの有効状態を適用」もあります。チェック状態を変更したら後者で保存してください。次回ゲーム起動時に反映されます。

リージョン間でプラグインを同期する前に、コピー先の Dalamud API とプラグインのバージョンが対応しているかを確認してください。同期は選択したコピー先のデータを上書きします。現時点では、繁体字中国語版のプラグイン DLL を他のゲームリージョンのものと混用しないでください。

## 設定と認証情報

既定のデータディレクトリは次のとおりです。

```text
~/.local/share/xivlauncher-super/
├── ffxiv_cn/     # 中国版のデータ
├── ffxiv_tc/     # 繁体字中国語版のデータ
├── ffxiv/        # グローバル版のデータ
├── compatdata/  # 既定の共用環境。pfx を含みます
└── logs/        # 診断ログ
```

プログラムは `XDG_DATA_HOME` に従います。Steam や Proton などの共通設定はランチャーのデータディレクトリに保存し、アカウントと Dalamud データはゲームリージョンごとに分離します。

認証情報は各ゲームリージョンのディレクトリ内の `credentials.json` に平文で保存されます。パスワード、2FA シークレット、クイックログイン認証情報は暗号化されません。作成する認証情報ファイルは所有者のみ読み書き可能です。アップロードや共有はしないでください。



2FA シークレットと 6 桁の認証コードは別のものです。シークレットはコードの生成に使い、認証コードはそのときのログインでのみ入力します。シークレット欄に 6 桁のコードを入力しないでください。

## ソースからのビルド

.NET 10 SDK、C コンパイラー、Python 3、Git、`7z` が必要です。ビルドとパッケージ作成時に、NuGet 依存パッケージ、固定バージョンの補助コンポーネント、および対応ソースコードをダウンロードする場合があります。

リポジトリのルートで実行します。

```bash
# Linux ランチャーをビルド
dotnet build src/XIVLauncher.Linux/XIVLauncher.Linux.csproj -c Release -m:1

# オフラインテストを実行
dotnet test src/XIVLauncher.Linux.Tests/XIVLauncher.Linux.Tests.csproj \
  -c Release -m:1 --filter "Category!=Network"

# 記録済みのライセンス資料を確認
python3 scripts/check-compliance-materials.py

# 実行パッケージと対応ソースの添付ファイルを生成
bash scripts/package-linux.sh
```

既定の出力先は `artifacts/linux/` です。再度パッケージを作成する場合は、新しい出力ディレクトリを指定してください。

```bash
bash scripts/package-linux.sh artifacts/local-build
```

完全なパッケージ作成では、ライセンス、依存関係の通知、対応ソースの添付ファイル、`SOURCE-DELIVERY.json`、チェックサムを生成します。再配布時は通知を保持し、適用されるライセンスに従って対応ソースも提供してください。詳細は[ソース提供の説明](compliance/SOURCE-DELIVERY.txt)をご覧ください。
