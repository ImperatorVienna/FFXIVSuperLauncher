# FFXIV Super Launcher 2.2.0

Windows x64 と Linux x86_64 を同時に正式リリースします。画面と主要機能を共用し、ゲーム起動とシステム連携はプラットフォーム別に処理します。

## Windows 版

- 中国版、繁体字中国語版、グローバル版のネイティブ起動と Dalamud 注入に対応します。初回設定では Steam / Proton のパス設定を省略し、Linux の互換性設定画面は表示しません。
- 実行コンポーネントを含む `FFXIV Super Launcher` フォルダーを ZIP で配布します。全体を展開して `FFXIVSuperLauncher.exe` を実行してください。EXE だけを移動しないでください。
- 固定の起動スクリプトとアイコン付きデスクトップショートカットを更新します。スタートメニューには登録しません。移動や名前変更後は EXE を直接一度起動してパスを更新してください。
- Windows の自己更新は専用 ZIP を取得し、署名とファイルハッシュを検証します。ランチャー終了後に一覧内のプログラムファイルを置き換え、ユーザーデータを保持します。インストール失敗時は復元を試みます。
- 本リリースに合わせて Windows のソースコードを公開します。

## 修正と改善

- クライアントパス、ディレクトリの包含関係、ファイルアクセスをプラットフォーム別に処理し、Windows の有効なパスや既存のプラグイン・リポジトリデータを正しく認識できない問題を修正しました。
- Windows のフロントエンド終了時にバックエンドセッションも終了し、ゲーム内データセンタートラベルの通信が失われる問題を修正しました。Windows のローカル待ち受けと Linux/Proton 通信を分離しました。
- Dalamud 更新が長引く場合、待機の継続、利用可能なローカルコンポーネントの使用、Dalamud を無効にして起動する選択肢を提供します。切り替え前に書き込みを停止し、更新と起動による同時変更を防ぎます。
- ランタイムとコンポーネントを一時領域で検証してから置き換え、失敗時は元のディレクトリを保持または復元します。段階別の診断によりネットワーク待ちとインストール失敗を区別しやすくしました。
- 共通 QR ログインの期限切れとキャンセル処理を修正しました。期限切れ時は一度コードを更新し、再度タイムアウトした場合もアカウント全体を削除せずにログインをやり直せます。公式認証サービスによるすべての拒否を解消するものではありません。
- Steam 未起動などのログイン失敗について表示と診断を改善しました。
- 中国語のクライアント分類表記を統一し、操作画面を改善しました。

## ダウンロードと更新

- Linux：`xivlauncher-super-2.2.0-x86_64.AppImage`。
- Windows：`FFXIVSuperLauncher-2.2.0-win-x64.zip`。
- 両プラットフォームとも設定、認証情報、プラグイン、ログをランチャーと同じディレクトリに保存します。更新や移動時は必要なデータを保持してください。個人の `credentials.json`、セッションファイル、非公開ログを公開リポジトリへアップロードしないでください。
- Linux の既存 Proton データパスは保持し、自動移行しません。移動する場合はゲームとランチャーを終了し、`compatdata` フォルダー全体を移して新しいパスを指定してください。パスだけを変更すると新規環境が作成され、個人のゲーム設定は移行されません。
- Linux の Steam 全画面表示、スクリーンキーボード、Proton 設定は引き続き利用できます。Windows の Steam アカウント認証には起動中の Steam が必要ですが、Proton や互換ツール登録は不要です。

## 検証とフィードバック

先行テストパッケージは両プラットフォームでプレイヤーによるゲーム起動確認を受けています。QR 復旧処理には模擬サービスによる回帰テストがあります。Windows 実機でのオンライン更新から終了・再起動までの全工程は引き続き検証が必要です。[GitHub Issues](https://github.com/ImperatorVienna/FFXIVSuperLauncher/issues) に OS、バージョン、再現手順、機密情報を除去した診断ログを添えて報告してください。
