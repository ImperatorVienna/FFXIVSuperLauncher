# FFXIV Super Launcher 2.2.0

Windows x64 與 Linux x86_64 雙平台正式發行。兩端共用介面與核心功能，遊戲啟動及系統整合則依平台處理。

## 新增 Windows 版

- 原生 Windows 遊戲啟動及 Dalamud 注入，支援中國版、繁體中文版與國際版；初次設定略過 Steam / Proton 路徑設定，不顯示 Linux 相容層頁面。
- 以 `FFXIV Super Launcher` 資料夾 ZIP 發行，內附執行元件。完整解壓縮後執行 `FFXIVSuperLauncher.exe`，請勿只移動 EXE。
- 自動維護固定啟動指令碼及附有圖示的桌面捷徑，不註冊開始功能表。移動或重新命名後，直接執行 EXE 一次即可更新路徑。
- Windows 自動更新下載專用 ZIP，驗證簽章與檔案雜湊，等待啟動器結束後依清單替換程式檔案、保留使用者資料，安裝失敗時嘗試還原。
- Windows 原始碼隨本版本一併公開。

## 修正與改善

- 依平台處理用戶端路徑、目錄包含關係及檔案存取，修正 Windows 無法正確辨識有效用戶端路徑及既有外掛、倉庫資料的問題。
- 修正 Windows 前端結束後背景工作階段意外結束，導致遊戲內跨大區通訊失效的問題；分離 Windows 本機監聽與 Linux/Proton 通訊實作。
- 改善 Dalamud 更新等待：長時間未完成時，可選繼續等待、使用可用的本機元件或停用 Dalamud 啟動。切換前先停止背景寫入，避免更新與啟動同時修改檔案。
- 執行環境與元件先暫存、驗證再替換，失敗時保留或還原原目錄；新增分階段診斷，方便區分網路等待與安裝失敗。
- 修正共用掃碼流程的 QR 碼過期與取消處理：過期後自動換碼一次，再次逾時可重新登入，不會因 QR 碼過期刪除整個帳號。此修正不表示所有官方驗證拒絕均已解決。
- 改善 Steam 未執行等登入失敗的提示與診斷。
- 統一中文「遊戲版本／中國版／繁體中文版／國際版」等文字，並最佳化操作介面。

## 下載與升級

- Linux：`xivlauncher-super-2.2.0-x86_64.AppImage`。
- Windows：`FFXIVSuperLauncher-2.2.0-win-x64.zip`。
- 兩端設定、憑證、外掛及記錄均存於啟動器所在目錄。升級或移動時保留所需資料；請勿將自己的 `credentials.json`、記錄或工作階段檔案上傳至公開儲存庫。
- Linux 既有 Proton 資料目錄沿用原設定，不自動搬移。需要搬移時，請結束遊戲與啟動器，移動完整 `compatdata` 資料夾並重新指定路徑；只改路徑會建立新環境，不會自動搬移遊戲個人設定。
- Linux 保留 Steam 全螢幕、虛擬鍵盤與 Proton 設定。Windows 的 Steam 帳號驗證需先執行 Steam，不需要 Proton 或相容性工具註冊。

## 驗證與回報

先前雙平台測試包已有玩家實際啟動驗證；本次掃碼復原有模擬介面回歸測試。Windows 完整線上自動更新及其結束、重新啟動流程仍需進一步實機驗證。請透過 [GitHub Issues](https://github.com/ImperatorVienna/FFXIVSuperLauncher/issues) 提供系統、版本、重現步驟及移除敏感資訊的診斷記錄。
