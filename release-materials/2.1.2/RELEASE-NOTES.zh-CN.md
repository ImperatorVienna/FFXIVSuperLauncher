# FFXIV Super Launcher 2.1.2

本次更新改进 Linux 便携存储、首次配置和应用菜单集成，并修复插件管理与网页验证的交互问题。

## 修复与功能改进

- 启动器配置、凭据、插件数据、日志以及 Electron 和内置浏览器的缓存、会话、临时文件改为保存在 AppImage 所在目录下。启动脚本也保存在该目录，运行 AppImage 时更新自身路径；应用菜单入口仍使用系统应用菜单目录。
- 将应用菜单入口与便携数据目录分离；菜单入口继续遵循系统目录规范，保留启动时注册及缓存刷新。
- 完善 Linux 首次配置的 Steam 路径扫描：仅发现一个有效路径且尚未设置时自动填入并保存；不覆盖手动设置，存在多个候选路径时由用户选择。国际版 Steam 登录认证本身不要求手动指定 Steam 路径，Linux 的 Proton 环境配置仍需要相应路径。
- 修复修改插件启用状态后插件与仓库复选框持续禁用、需要切页或刷新才能恢复的问题。
- 修复繁体中文版登录网页验证超出验证区域的问题，使网页随页面滚动并裁剪在可见区域内。
- 整理平台相关接口，为后续 Windows 版开发准备共用功能与平台实现的边界；本次未替换固定的第三方辅助组件。

## 升级与数据目录说明（请先阅读）

- 请将 AppImage 放在可写目录。旧数据不会自动迁移或删除；从旧版升级后，如需沿用原设置，请在退出游戏和启动器后，将原数据目录（通常为 `~/.local/share/xivlauncher-super/`，旧版遵循 `XDG_DATA_HOME`）中的配置及所需数据搬到新 AppImage 旁。没有这些配置时，新版会进入首次配置流程。
- **已有配置中保存的 Proton 数据目录仍按原路径使用，不会自动改成新默认位置。** 无需迁移时可继续保留原路径；若要迁移，请退出游戏和启动器，将整个 `compatdata` 文件夹搬到新位置，然后在“Steam 和 Proton 设置”中重新选择 `compatdata` 这一层，不能选择里面的 `pfx`。仅改路径、不搬文件会创建新容器，原容器中的游戏设置不会自动带过去。
- 首次使用时，共用 Proton 数据目录默认为 AppImage 旁的 `compatdata`，实际容器在需要时创建。手动指定目录及国际版复用的 Steam pfx 不会被强制迁移。
- 以后移动启动器时，请同时移动需要保留的数据；已有绝对路径设置须自行核对。移动或重命名 AppImage 后直接运行一次，以刷新 Steam 和应用菜单入口。旧版程序仍按旧版规则读取数据，回滚程序不会自动回滚或搬迁配置。

## 下版本预告

下一版本计划提供 Windows 版，复用现有界面与核心功能，并采用 Windows 原生的游戏启动和系统集成。本次 2.1.2 仍仅发行 x86_64 Linux AppImage，不包含可供使用的 Windows 发行包。
