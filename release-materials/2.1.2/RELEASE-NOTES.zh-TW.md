# FFXIV Super Launcher 2.1.2

本次更新改善 Linux 可攜式儲存、首次設定與應用程式選單整合，並修正外掛管理及網頁驗證的互動問題。

## 修正與功能改善

- 啟動器設定、憑據、外掛資料、日誌，以及 Electron 和內建瀏覽器的快取、工作階段、暫存檔，改為儲存在 AppImage 所在目錄下。啟動指令稿也儲存在該目錄，執行 AppImage 時更新自身路徑；應用程式選單入口仍使用系統應用程式選單目錄。
- 將應用程式選單入口與可攜式資料目錄分離；選單入口繼續遵循系統目錄規範，保留啟動時註冊與快取更新。
- 完善 Linux 首次設定的 Steam 路徑掃描：僅找到一個有效路徑且尚未設定時，自動填入並儲存；不覆蓋手動設定，有多個候選路徑時由使用者選擇。國際版 Steam 登入驗證本身不要求手動指定 Steam 路徑，Linux 的 Proton 環境設定仍需要相應路徑。
- 修正變更外掛啟用狀態後，外掛與倉庫核取方塊持續停用，必須切換頁面或重新整理才能恢復的問題。
- 修正繁體中文版登入網頁驗證超出驗證區域的問題，使網頁隨頁面捲動並裁切於可見區域內。
- 整理平台相關介面，為後續 Windows 版開發劃分共用功能與平台實作；本次未替換固定的第三方輔助元件。

## 升級與資料目錄說明（請先閱讀）

- 請將 AppImage 放在可寫入的目錄。舊資料不會自動遷移或刪除；從舊版升級後，如需沿用原設定，請先退出遊戲和啟動器，再將原資料目錄（通常為 `~/.local/share/xivlauncher-super/`，舊版遵循 `XDG_DATA_HOME`）中的設定及所需資料搬到新 AppImage 旁。沒有這些設定時，新版會進入首次設定流程。
- **既有設定中儲存的 Proton 資料目錄仍沿用原路徑，不會自動改為新的預設位置。** 無須遷移時可繼續保留原路徑；若要遷移，請退出遊戲和啟動器，將整個 `compatdata` 資料夾搬到新位置，再於「Steam 與 Proton 設定」中重新選擇 `compatdata` 這一層，而非其中的 `pfx`。僅變更路徑而未搬移檔案，會建立新容器，原容器中的遊戲設定不會自動帶入。
- 首次使用時，共用 Proton 資料目錄預設為 AppImage 旁的 `compatdata`，實際容器在需要時建立。手動指定目錄及國際版沿用的 Steam pfx 不會被強制遷移。
- 日後移動啟動器時，請一併移動需要保留的資料，並自行核對既有的絕對路徑設定。移動或重新命名 AppImage 後直接執行一次，以更新 Steam 和應用程式選單入口。舊版程式仍按舊版規則讀取資料，回復舊版程式不會自動回復或遷移設定。

## 下版本預告

下一版本計畫提供 Windows 版，沿用現有介面與核心功能，並採用 Windows 原生的遊戲啟動和系統整合。本次 2.1.2 仍僅發行 x86_64 Linux AppImage，不包含可供使用的 Windows 發行套件。
