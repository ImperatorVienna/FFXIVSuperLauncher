# 下一版更新计划

## 统一国际版 Steam 版的名称

状态：已记录，待下一版实施。用户于 2026-10-12 提出。

统一使用以下名称：

| 语言 | 标准名称 |
| --- | --- |
| 简体中文 | 国际版（Steam 版） |
| 繁體中文 | 國際版（Steam 版） |
| English | Global (Steam Version) |
| 日本語 | グローバル版（Steam 版） |

实施范围：检查前端标签、提示、弹窗、新手引导、后端面向用户的提示，以及现行 README 和使用说明；凡明确指国际版 Steam 版本的描述，统一采用上述名称。英文中的 Global (Steam) 等旧写法应替换为 Global (Steam Version)。整句需按各语言语法自然调整。

边界：不将普通国际版、非 Steam 版账户或仅描述“通过 Steam 启动”的文案改为 Steam 版本；不修改内部区服标识、配置键、Steam App ID 或运行逻辑；保留已发行版本的历史公告和归档原文。

验收：搜索旧写法并逐项检查语义，核对四种语言展示和长文本布局。此次仅记录计划，不修改已发布的 2.1.1 包。

不修改内部区服标识 `ffxiv_tc`、配置键及运行逻辑；保留已经发行版本的历史公告和归档原文。与上项名称统一一并在下一版实施，不覆盖已发布的 2.1.1 包。

## 检查中英文混排空格

状态：已记录，与上述名称统一一并在下一版实施。

- 修正后的标准名称：简中“国际版（Steam 版）”、繁中「國際版（Steam 版）」、英文 `Global (Steam Version)`、日文「グローバル版（Steam 版）」。
- 全面检查现行界面与文档的中英文混排：汉字与英文单词、产品名及数字之间保留必要空格，例如“Steam 版”“启用 Dalamud”“Proton 版本”“2FA 验证码”。繁中对应处理；日文沿用既有日文排版约定，统一上述 Steam 版名称。
- 中文全角括号内侧不额外加空格，例如“国际版（Steam 版）”，不写作“国际版（ Steam 版 ）”。
- 覆盖标签、提示、弹窗、新手引导、后端面向用户的提示、README 和现行使用说明；同步检查翻译键与引用，避免只改键名导致翻译失效。
- 不拆分 URL、路径、配置键、内部标识、命令、代码及产品官方拼写；不追改历史发行公告和归档。
- 验收时搜索混排疑似缺空格位置，逐条人工判断，避免无差别替换破坏语义或运行逻辑。

日文补充约定：参照既有「繁体字中国語版」的命名方式，保留日文使用「版」的表达，不机械套用中文的「区」。对应名称为「繁体字中国語版」「グローバル版」「グローバル版（Steam 版）」。整句按日文语法自然表述，Steam 与「版」之间保留空格。

## 中文客户端分类统一使用“版／版本”

状态：已记录，待下一版实施。2026-10-13 的最新要求覆盖前述中文命名约定中旧的“区／区服”表述。

| 原文 | 简体中文标准写法 | 繁體中文標準寫法 |
| --- | --- | --- |
| 游戏区服 | 游戏版本 | 遊戲版本 |
| 区服（指客户端分类） | 版本 | 版本 |
| 中国区 | 中国版 | 中國版 |
| 繁中区／繁体中文区 | 繁体中文版 | 繁體中文版 |
| 国际区 | 国际版 | 國際版 |
| 国际区（Steam 版） | 国际版（Steam 版） | 國際版（Steam 版） |

覆盖所有现行简繁中文标签、提示、弹窗、新手引导、后端面向用户的提示和文档，包含“选择游戏版本”“当前游戏版本”等上下文；现有“语言和区服”页签相应改为“语言和版本”，简繁同步。描述不同客户端之间同步时相应改为“在不同游戏版本间同步”。

此项不更改日英文既定称呼。内部 `ffxiv_cn`、`ffxiv_tc`、`ffxiv` 标识、配置键和协议不变；涉及翻译查找的中文键与引用须同步更新。

按语义区分客户端版本和真实服务器：游戏“大区”、数据中心、“跨区”“返回原区”等实际服务器概念不机械替换成“版”，避免改变功能含义。历史发行公告和归档仍保留原文。验收时检查遗漏、翻译完整性和长文本布局。
