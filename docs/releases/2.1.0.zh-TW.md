# FFXIV Super Launcher 2.1.0

2.1.0 著重改善中國區遊戲內跨大區體驗，加入授權恢復和儲存空間清理，並完善 Proton 環境下的背景工作階段管理。

## 新增與改進

- 新增 DCTravelerX（[Dalamud-DailyRoutines/DCTraveler](https://github.com/Dalamud-DailyRoutines/DCTraveler)）通訊適配，透過本啟動器啟動中國區遊戲後，可由外掛取得大區資訊並呼叫跨區服務。
- 遊戲啟動後自動關閉前端介面以降低資源消耗，背景程序繼續維護遊戲工作階段、跨區授權和 Steam 遊戲執行狀態；再次開啟啟動器可使用前端功能。
- 跨區授權過期時優先使用快速登入憑證恢復。仍需掃碼時，無須退出遊戲，再次開啟啟動器使用目前遊戲帳號掃碼即可；「重新授權遊戲內跨區」按鈕位於「超域傳送」下方。恢復後回到遊戲重新操作即可。
- 「關於」新增「儲存空間清理」：清理下載快取、清理日誌、清理內建瀏覽器快取。瀏覽器快取清理保留 Cookie 和驗證狀態；啟動器不接管 Dalamud 自行管理的快取和日誌。
- 啟動時自動回收可確認失效的跨區工作階段記錄及已知暫存檔，保留活動工作階段和無法確認安全性的記錄。
- 補齊新增按鈕、說明、授權提示和清理結果的简体中文、繁體中文、日本語及 English 文案。

## 修復與穩定性

- 改進遊戲程序、Proton 環境和背景工作階段識別，依操作需求判斷占用狀態，減少無關背景程序造成的誤攔截。
- 下載、安裝和下載快取清理共同使用跨程序鎖，避免檢查完成後另一個工作開始寫入快取的競爭問題。
- 日誌清理透過日誌模組處理目前檔案；其他活動程序使用中或無法安全處理的檔案顯示為略過。
- 完善跨區授權取消、逾時、初始化失敗和退出時的資源釋放；背景掃碼最長等待五分鐘。
- 工作階段掃描不再因殘留記錄遺漏有效工作階段；修正部分術語替換造成的本地化比對問題。

## 使用說明

- 發行格式仍為 x86_64 Linux AppImage，內建 .NET 和 Electron，繼續使用現有設定和憑證。
- 遊戲內跨大區適配針對 DCTravelerX，不代表 ottercorp DcTraveler 或其他外掛已相容。需要啟用中國區 Dalamud 並安裝相容版本的外掛。
- 關閉介面後請保留啟動器背景程序。若跨區請求結果不明確，請先檢查官方訂單狀態；啟動器不會自動重複提交。
- 遊戲執行時可進行儲存空間清理；下載或安裝期間不能清理下載快取，操作或網頁驗證期間不能清理內建瀏覽器快取。清理零個檔案屬於正常結果。
- 內建瀏覽器清理不包含舊版獨立驗證碼瀏覽器的遺留目錄；憑證、遊戲設定、已安裝元件和備份不會作為下載快取刪除。
