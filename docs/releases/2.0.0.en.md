# FFXIV Super Launcher 2.0.0

2.0.0 replaces the legacy 1.0.0 interface with a new Electron graphical interface, while continuing to support the China, Traditional Chinese, and Global clients on Linux.

## Additions and improvements

- A new dark interface using GenRyu and Cinzel fonts, with consistent buttons, dropdowns, scrollbars, and transparent dialogs with background blur. Switch instantly between Simplified Chinese, Traditional Chinese, Japanese, and English without restarting.
- Login verification is grouped below “Start game”, including China QR-code login, manual verification codes, and Traditional Chinese web verification. Logs now appear in a scrollable overlay that users expand manually, support selection and copying, and show the full diagnostic log storage path on every page.
- Added dedicated third-party plugin repository management, supporting adding, editing, enabling/disabling, deleting, checking connections, and cross-region synchronization. Connection results appear below the corresponding repository.
- Replaced “Sync Dalamud settings” with “Sync third-party repositories”, synchronizing only the third-party repository list and enablement states, while always preserving the destination region’s main repository, preset repository toggle, and other Dalamud settings. The source region cannot also be selected as a destination, and backups are retained before synchronization.
- Individual settings such as plugin enablement states, interface language, and Global client language are now saved immediately. Plugin enablement states and client language take effect on the next game launch; login credentials still use a single save after completing the fields.
- “About” now includes an “Automatically check for updates” toggle, enabled by default. Stable releases are checked automatically after initial setup is complete; users can subsequently disable this, while manual checks remain available. Run an older AppImage to roll back, then turn off automatic update checks.
- “About” now includes an “Artwork sources” list, grouping source links for the icon, GenRyu, and Cinzel. The distribution includes font licenses and source records.

## Fixes and stability

- Fixed stalled Traditional Chinese web verification and leftover verification processes after cancellation or exit that could prevent subsequent launches.
- Fixed update checks affected by China’s preset plugin repositories and different API versions of plugins sharing the same name.
- Fixed plugins and repositories remaining uneditable after the game exits. Changes to plugins, repositories, client language, paths, and the compatibility environment are blocked while the game is running to prevent conflicts with the running game or plugins.
- Plugins and repositories display their own operation results and errors, and refreshing their respective states clears the messages. Fixed duplicate errors, messages displayed in the wrong place, and refresh actions on either side disabling one another.
- Separated save results from subsequent refreshes: when saving succeeds but refreshing fails, this is stated explicitly to avoid incorrectly reporting a save failure. After initial setup is complete, a failure to read credentials no longer prevents returning to the main interface.
- Proton/Steam environment scanning now uses a separate read with a time limit; a scan timeout no longer directly terminates the entire backend. Write operations retain timeout protection, and writes with uncertain outcomes are not automatically retried. Dalamud network timeout handling and local-version fallback remain unchanged.
- Reduced interface redraws when nothing has changed and background polling while minimized. Improved resource cleanup when verification is cancelled, fails, or exits, and removed the legacy frontend, obsolete controls, and text with no remaining callers.

## Usage notes

- The distribution is an x86_64 Linux AppImage with .NET and Electron included. Existing configuration can continue to be used; the first launch of the new version refreshes the fixed launch entry used by Steam and the application menu.
- Credentials continue to be stored locally in plaintext by game region; no encrypted storage is added.
- This release does not add game personal settings migration or backup.
- Previously verified third-party runtime components are retained and are not upgraded alongside this interface update.
