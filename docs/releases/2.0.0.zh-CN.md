# FFXIV Super Launcher 2.0.0

2.0.0 以全新的 Electron 图形界面取代 1.0.0 的旧界面，继续支持 Linux 上的中国区、繁中区和国际区客户端。

## 新增与改进

- 全新暗色界面，采用 GenRyu 和 Cinzel 字体，统一按钮、下拉菜单、滚动条和透明模糊弹窗。简体中文、繁體中文、日本語和 English 可即时切换，无须重启。
- 登录验证集中显示在“开始游戏”下方，包括中国区扫码、手动验证码和繁中区网页验证。日志改为由用户手动展开的可滚动浮层，支持选择和复制，所有页面均显示完整诊断日志存放路径。
- 新增独立的第三方插件仓库管理，支持添加、编辑、启用/停用、删除、检查连接和跨区服同步；连接结果显示在对应仓库下方。
- 将原“同步 Dalamud 设置”替换为“同步第三方仓库”，仅同步第三方仓库列表及启用状态，始终保留目标区服的主仓库、预置仓库开关及其他 Dalamud 设置。来源区服不能同时选为目标，同步前保留备份。
- 插件启用状态、界面语言、国际区客户端语言等单项设置改为即时保存。插件启用状态和客户端语言在下次启动游戏时生效；登录凭据保留填写后统一保存的方式。
- “关于”新增默认开启的“自动检查更新”开关。首次配置完成后自动检查稳定版，之后可自行关闭；手动检查仍可使用。运行旧版本 AppImage 可回滚，回滚后请关闭自动检查更新。
- “关于”新增“美术素材来源”列表，统一提供图标、GenRyu 和 Cinzel 的来源入口；发行包附带字体许可证及来源记录。

## 修复与稳定性

- 修复繁中区网页验证卡住，以及取消或退出后验证进程残留、妨碍再次启动的问题。
- 修复中国区预置插件仓库及同名插件不同 API 版本影响更新检查的问题。
- 修复退出游戏后插件和仓库仍被判定为不可编辑的问题。游戏运行时禁止修改插件、仓库、客户端语言、路径和兼容环境，防止与运行中的游戏或插件冲突。
- 插件与仓库分别显示操作结果和错误，刷新各自状态后清除提示；修复重复报错、提示显示在错误位置及两侧刷新相互禁用的问题。
- 将保存结果与后续刷新分开：已经保存但刷新失败时明确提示，避免误报为保存失败。首次设置完成后，凭据读取失败不会阻止返回主界面。
- Proton/Steam 环境扫描改为独立限时读取，扫描超时不会直接终止整个后端；写入操作仍保留超时保护，不自动重试结果不明确的写入。Dalamud 网络超时及本地版本回退机制保持不变。
- 减少无变化的界面重绘和最小化后的后台轮询；完善验证取消、失败及退出时的资源清理，并清除旧前端、旧控件和失去调用方的文案。

## 使用说明

- 发行包为 x86_64 Linux AppImage，内置 .NET 和 Electron。已有配置可继续使用；首次运行新版会刷新 Steam 和应用菜单的固定启动入口。
- 凭据继续按区服以明文保存在本地，不新增加密存储。
- 本次未加入游戏个人设定档迁移或备份功能。
- 沿用已经验证的第三方运行组件，不随本次界面升级顺带更新。
