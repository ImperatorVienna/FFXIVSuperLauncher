# FFXIV Super Launcher 2.1.0

2.1.0 improves in-game cross-data-center travel for China, adds authorization recovery and storage cleanup, and improves backend session management under Proton.

## New and improved

- Adds communication support for DCTravelerX ([Dalamud-DailyRoutines/DCTraveler](https://github.com/Dalamud-DailyRoutines/DCTraveler)). After launching the China client through this launcher, the plugin can retrieve data-center information and call travel services.
- Automatically closes the frontend after game launch to reduce resource usage. The backend continues maintaining the game session, travel authorization, and Steam game-running status; reopen the launcher to access the frontend.
- Expired travel authorization is first recovered using saved quick-login credentials. If QR verification is needed, reopen the launcher and scan with the account currently in the game, without exiting the game. “Reauthorize in-game DC travel” appears below the travel button. Retry the action in the game after recovery.
- Adds Storage cleanup to About: clear download cache, logs, and built-in browser cache. Browser cleanup preserves cookies and verification state; the launcher does not take over caches or logs managed by Dalamud itself.
- Startup reclaims travel-session records and known temporary files confirmed to be stale, preserving active sessions and records whose safety cannot be confirmed.
- Completes Simplified Chinese, Traditional Chinese, Japanese, and English translations for new buttons, descriptions, authorization prompts, and cleanup results.

## Fixes and stability

- Improves identification of game processes, Proton environments, and backend sessions, applying occupancy checks appropriate to each operation and reducing false blocks caused by unrelated background processes.
- Downloads, installation, and download-cache cleanup share a cross-process lock, preventing another task from writing to the cache after the initial check.
- Current logs are cleared through the logging module. Files used by other active processes or unsafe to handle are reported as skipped.
- Improves resource release on authorization cancellation, timeout, initialization failure, and exit. Backend QR verification waits at most five minutes.
- Stale records no longer hide valid sessions during scanning; fixes terminology substitutions that prevented some translations from matching.

## Usage notes

- Distribution remains an x86_64 Linux AppImage with .NET and Electron included. Existing settings and credentials remain usable.
- In-game travel support targets DCTravelerX, not a guarantee of compatibility with ottercorp DcTraveler or other plugins. Enable China Dalamud and install a compatible plugin version.
- Keep the backend process running after the interface closes. If a travel request has an uncertain result, check the official order status first; the launcher does not automatically resubmit it.
- Storage cleanup is available while the game is running. Download-cache cleanup is blocked during downloads or installation, and browser-cache cleanup is blocked during operations or web verification. Clearing zero files is a normal result.
- Browser cleanup excludes legacy standalone verification-browser directories. Credentials, game settings, installed components, and backups are not deleted as download caches.
