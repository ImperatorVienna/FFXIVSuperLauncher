# FFXIV Super Launcher 2.1.0

2.1.0 重点改进中国区游戏内跨大区体验，加入授权恢复和存储清理，并完善 Proton 环境下的后台会话管理。

## 新增与改进

- 新增 DCTravelerX（Dalamud-DailyRoutines/DCTraveler）通信适配，通过本启动器启动中国区游戏后，可由插件获取大区信息并调用跨区服务。
- 游戏启动后可以关闭前端界面，后台继续维护游戏会话、跨区授权和 Steam 状态；再次打开启动器可使用前端功能。
- 跨区授权过期时优先使用快捷登录凭据恢复。仍需扫码时，无须退出游戏，打开启动器使用当前游戏账号扫码即可；“重新授权游戏内跨区”按钮位于“超域传送”下方。恢复后回到游戏重新操作。
- “关于”新增“存储清理”：清理下载缓存、清理日志、清理内置浏览器缓存。浏览器缓存清理保留 Cookie 和验证状态；启动器不接管 Dalamud 自行管理的缓存和日志。
- 启动时自动回收可确认失效的跨区会话记录及已知临时文件，保留活动会话和无法确认安全性的记录。
- 补齐新增按钮、说明、授权提示和清理结果的简体中文、繁體中文、日本語及 English 文案，调整存储清理区域间距。

## 修复与稳定性

- 改进游戏进程、Proton 环境和后台会话识别，按操作需求判断占用状态，减少无关后台进程造成的误拦截。
- 下载、安装和下载缓存清理共同使用跨进程锁，避免检查完成后另一个任务开始写入缓存的竞争问题。
- 日志清理通过日志模块处理当前文件；其他活动进程使用中或无法安全处理的文件显示为跳过。
- 完善跨区授权取消、超时、初始化失败和退出时的资源释放；后台扫码最长等待五分钟。
- 会话扫描不再因残留记录遗漏有效会话；修正部分术语替换造成的本地化匹配问题。

## 使用说明

- 发行格式仍为 x86_64 Linux AppImage，内置 .NET 和 Electron，继续使用现有设置和凭据。
- 游戏内跨大区适配面向 DCTravelerX，不代表 ottercorp DcTraveler 或其他插件已兼容。需要启用中国区 Dalamud 并安装兼容版本的插件。
- 关闭界面后请保留启动器后台进程。若跨区请求结果不明确，请先检查官方订单状态；启动器不会自动重复提交。
- 游戏运行时可执行存储清理；下载或安装期间不能清理下载缓存，操作或网页验证期间不能清理内置浏览器缓存。清理零个文件属于正常结果。
- 内置浏览器清理不包含旧版独立验证码浏览器的遗留目录；凭据、游戏设置、已安装组件和备份不会作为下载缓存删除。
