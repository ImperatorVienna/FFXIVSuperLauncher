# FFXIV Super Launcher 2.1.1

今回の更新では、Steam ゲーミングモードでの起動互換性、ゲーム内データセンタートラベルの状態照会、初回設定の問題を中心に修正しました。

## 修正と機能改善

- 一部の Gamescope セッションで、D3D11 と DXGI の読み込み設定の不一致によりゲームがクラッシュする問題を修正しました。Dalamud の有効・無効にかかわらず適用されます。`dxgi=n` を継承し、明示的な D3D11 設定がなく、競合するレンダラー設定が選択されていない場合のみ不足分を補います。既存の D3D11 や WineD3D 設定は上書きしません。
- 中国版の DCTravelerX によるゲーム内トラベルの申請状態照会を改善しました。確立済みのトラベルセッションを再利用し、照会のたびに初期化し直す処理を避けます。認証失効時の復旧は維持し、トラベル申請を自動で再送することはありません。申請送信、状態照会、認証の問題を区別できるよう診断ログを追加しました。
- Steam 互換性ツールの登録を「Steam 起動に対応」に統合しました。有効にすると、Steam からの起動時（デスクトップと Gamescope の両方）に自動で全画面表示となり、入力欄から Steam の仮想キーボードを呼び出せます。呼び出せない場合はキーボードでの入力を案内します。Steam の全画面表示とデスクトップのウィンドウサイズは別に保存します。「互換性ツール設定」は「Steam と Proton の設定」に変更しました。
- Ctrl+Q / Alt+F4 による正常終了に対応しました。全画面でもキーボードでランチャーを終了し、セッションをクリーンアップできます。Esc は引き続きダイアログのキャンセルに使用します。
- 初回設定を改善しました。既定の表示言語は English とし、ランチャー言語、ゲームリージョン、Steam / Proton 環境を順に設定します。グローバル版のクライアント言語、CDKey バージョン、EU アカウントのストア優先言語を追加しました。選択は即座に保存し、保存に失敗した場合は入力を保持して先に進まないようにします。ランチャーの更新確認は初回設定の完了後に行います。
- 自動更新ダイアログのエラー処理を改善しました。インストールの重複実行を防ぎ、失敗時はエラー表示を保持して再試行できるようにしました。一部の再読み込み操作で入力内容やフォーカスがリセットされる問題も修正しました。
- 一部のユーザーインターフェースを最適化しました。

## アップグレードについて

- 今回のグラフィックス DLL 問題の対策として追加した Steam 起動オプション `env WINEDLLOVERRIDES="dxgi,d3d11=n" %command%` は削除できます。それ以外の独自のオプションは残してください。
- Steam 互換性ツールの登録を変更した後は、Steam を再起動してください。既存の登録設定は引き継がれます。
- Proton、Dalamud、同梱のサードパーティーコンポーネントの管理方法は変更していません。固定された補助コンポーネントの差し替えや独自のコントローラーナビゲーションの追加もありません。Steam Deck ではトラックパッドでランチャーを操作できます。
- 対応プラットフォームは引き続き x86_64 Linux です。ゲーミングモード関連の変更は CachyOS 環境で実機テスト済みですが、すべての SteamOS デバイス、ディストリビューション、Proton バージョンを検証したわけではありません。
