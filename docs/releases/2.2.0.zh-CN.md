# FFXIV Super Launcher 2.2.0

Windows x64 与 Linux x86_64 双平台正式发行。两端共用界面和核心功能，游戏启动及系统集成按平台处理。

## 新增 Windows 版

- 使用原生 Windows 游戏启动和 Dalamud 注入，支持中国版、繁体中文版与国际版；新手引导跳过 Steam / Proton 路径设置，不显示 Linux 兼容层页面。
- 以 `FFXIV Super Launcher` 文件夹 ZIP 发行，内置运行组件。完整解压后运行 `FFXIVSuperLauncher.exe`，不要只移动 EXE。
- 自动维护固定启动脚本和带图标的桌面快捷方式，不注册开始菜单。移动或重命名后，直接运行 EXE 一次即可刷新路径。
- Windows 自更新下载专用 ZIP，校验签名和文件哈希，等待启动器退出后按清单替换程序文件、保留用户数据，并在安装失败时尝试回滚。
- Windows 源码与本次版本一并公开。

## 修复与改善

- 按平台处理客户端路径、目录包含关系和文件访问，修复 Windows 下有效客户端路径与已有插件、仓库数据无法正确识别的问题。
- 修复 Windows 前端退出后后台会话意外结束，导致游戏内跨大区通信失效的问题；分离 Windows 本地监听与 Linux/Proton 通信实现。
- 改善 Dalamud 更新等待：长时间无结果时提供继续等待、使用可用本地组件或禁用 Dalamud 启动的选择；切换前先停止后台写入，避免更新与启动并行修改文件。
- 运行库和组件采用暂存、校验后替换，失败时保留或恢复原目录；增加分阶段诊断，方便区分网络等待与安装失败。
- 修复共用扫码流程的二维码过期及取消处理：过期后自动换码一次，再次超时可重新登录，不会因扫码过期删除整个账户。此修复不代表所有官方认证拒绝均已解决。
- 改善 Steam 未运行等登录失败的提示与诊断。
- 统一中文“游戏版本／中国版／繁体中文版／国际版”等文案，并对交互界面进行了优化。

## 下载与升级

- Linux：`xivlauncher-super-2.2.0-x86_64.AppImage`。
- Windows：`FFXIVSuperLauncher-2.2.0-win-x64.zip`。
- 两端配置、凭据、插件和日志均保存在启动器所在目录。升级或移动时保留需要的数据；不要把自己的 `credentials.json`、日志或会话文件上传到公开仓库。
- Linux 现有 Proton 数据目录保持原设置，不自动搬迁。需要迁移时，请退出游戏和启动器，移动整个 `compatdata` 文件夹并重新指定路径；仅修改路径会创建新环境，不会自动迁移游戏个人设置。
- Linux 的 Steam 全屏、虚拟键盘及 Proton 设置仍保留。Windows 的 Steam 账户认证要求 Steam 已启动，不需要 Proton 或兼容性工具注册。

## 验证与反馈

此前双平台测试包已有玩家实际启动验证；本次扫码恢复有模拟接口回归测试。Windows 完整在线自更新及其退出、重启过程仍需进一步实机验证。请通过 [GitHub Issues](https://github.com/ImperatorVienna/FFXIVSuperLauncher/issues) 提供系统、版本、复现步骤及脱敏诊断日志。
