# FFXIV Super Launcher 2.1.2

今回の更新では、Linux のポータブル保存、初回設定、アプリケーションメニューとの連携を改善し、プラグイン管理と Web 認証の操作上の問題を修正しました。

## 修正と機能改善

- ランチャーの設定、認証情報、プラグインデータ、ログ、および Electron と内蔵ブラウザーのキャッシュ、セッション、一時ファイルを AppImage と同じディレクトリ配下に保存するようにしました。起動スクリプトも同じ場所に保存し、AppImage の実行時に自身のパスを更新します。アプリケーションメニューのエントリーは引き続きシステムのメニューディレクトリに保存します。
- アプリケーションメニューのエントリーとポータブルデータの保存先を分離しました。メニューの保存先は引き続きシステムのディレクトリ規則に従い、起動時の登録とキャッシュ更新を維持します。
- Linux の初回設定で Steam のパス検出を改善しました。有効な候補が 1 つだけあり、まだパスが設定されていない場合にのみ、自動入力して保存します。手動設定は上書きせず、候補が複数ある場合はユーザーが選択します。グローバル版の Steam 認証自体に Steam パスの手動指定は不要ですが、Linux の Proton 環境設定には対応するパスが必要です。
- プラグインの有効状態を変更すると、プラグインとリポジトリのチェックボックスが無効のままになり、ページ切り替えや更新が必要になる問題を修正しました。
- 繁体字中国語版のログイン Web 認証が認証領域からはみ出す問題を修正しました。ページのスクロールに追従し、表示領域内に収まるように切り抜きます。
- Windows 版の開発に向けて、共通機能とプラットフォーム固有のインターフェースを整理しました。固定のサードパーティ補助コンポーネントは置き換えていません。

## アップグレードとデータディレクトリについて（必ずお読みください）

- AppImage は書き込み可能なディレクトリに置いてください。旧データは自動で移動・削除されません。従来の設定を引き継ぐには、ゲームとランチャーを終了し、旧データディレクトリ（通常は `~/.local/share/xivlauncher-super/`。旧版では `XDG_DATA_HOME` に従います）の設定と必要なデータを、新しい AppImage の隣に移してください。これらの設定がない場合は、初回設定が開きます。
- **既存の設定に保存された Proton データディレクトリは元のパスを使い続け、新しい既定の場所には自動変更されません。** そのまま使うこともできます。移動する場合はゲームとランチャーを終了し、`compatdata` フォルダー全体を移してから、「Steam と Proton の設定」で `compatdata` の階層を選び直してください。中の `pfx` は選択しないでください。パスだけを変更すると新しいコンテナーが作られ、元のゲーム設定は自動では引き継がれません。
- 新規設定時の共通 Proton データディレクトリは AppImage の隣の `compatdata` となり、必要になった時点でコンテナーを作成します。手動指定のディレクトリやグローバル版で再利用する Steam の pfx は強制移動しません。
- 今後ランチャーを移動するときは、保持したいデータも一緒に移動し、既存の絶対パス設定を確認してください。AppImage の移動・名前変更後は一度直接実行し、Steam とアプリケーションメニューのエントリーを更新してください。旧版は従来の規則でデータを読み込みます。実行ファイルを旧版に戻しても、設定が自動で復元・移動されるわけではありません。

## 次回予告

次のリリースでは Windows 版の提供を予定しています。現在の UI とコア機能を共有し、ゲーム起動とシステム連携には Windows ネイティブの実装を使用します。今回の 2.1.2 は引き続き x86_64 Linux AppImage のみで、利用可能な Windows 配布パッケージは含まれていません。
