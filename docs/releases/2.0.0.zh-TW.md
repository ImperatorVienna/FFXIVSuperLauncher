# FFXIV Super Launcher 2.0.0

2.0.0 以全新的 Electron 圖形介面取代 1.0.0 的舊介面，繼續支援 Linux 上的中國區、繁中區和國際區用戶端。

## 新增與改進

- 全新暗色介面，採用 GenRyu 和 Cinzel 字型，統一按鈕、下拉選單、捲軸和透明模糊彈窗。簡體中文、繁體中文、日本語和 English 可即時切換，無須重新啟動。
- 登入驗證集中顯示在「開始遊戲」下方，包括中國區掃碼、手動驗證碼和繁中區網頁驗證。日誌改為由使用者手動展開的可捲動浮層，支援選取和複製，所有頁面均顯示完整診斷日誌儲存路徑。
- 新增獨立的第三方外掛倉庫管理，支援新增、編輯、啟用/停用、刪除、檢查連線和跨區服同步；連線結果顯示在對應倉庫下方。
- 將原「同步 Dalamud 設定」替換為「同步第三方倉庫」，僅同步第三方倉庫清單及啟用狀態，始終保留目標區服的主倉庫、預置倉庫開關及其他 Dalamud 設定。來源區服不能同時選為目標，同步前保留備份。
- 外掛啟用狀態、介面語言、國際區用戶端語言等單項設定改為即時儲存。外掛啟用狀態和用戶端語言在下次啟動遊戲時生效；登入憑證保留填寫後統一儲存的方式。
- 「關於」新增預設開啟的「自動檢查更新」開關。首次設定完成後自動檢查穩定版，之後可自行關閉；手動檢查仍可使用。執行舊版本 AppImage 可回復版本，回復後請關閉自動檢查更新。
- 「關於」新增「美術素材來源」清單，統一提供圖示、GenRyu 和 Cinzel 的來源入口；發行套件隨附字型授權條款及來源記錄。

## 修復與穩定性

- 修復繁中區網頁驗證卡住，以及取消或退出後驗證程序殘留、妨礙再次啟動的問題。
- 修復中國區預置外掛倉庫及同名外掛不同 API 版本影響更新檢查的問題。
- 修復退出遊戲後外掛和倉庫仍被判定為不可編輯的問題。遊戲執行時禁止修改外掛、倉庫、用戶端語言、路徑和相容環境，防止與執行中的遊戲或外掛衝突。
- 外掛與倉庫分別顯示操作結果和錯誤，重新整理各自狀態後清除提示；修復重複報錯、提示顯示在錯誤位置及兩側重新整理相互停用的問題。
- 將儲存結果與後續重新整理分開：已經儲存但重新整理失敗時明確提示，避免誤報為儲存失敗。首次設定完成後，憑證讀取失敗不會阻止返回主介面。
- Proton/Steam 環境掃描改為獨立限時讀取，掃描逾時不會直接終止整個後端；寫入操作仍保留逾時保護，不自動重試結果不明確的寫入。Dalamud 網路逾時及本機版本回退機制保持不變。
- 減少無變化的介面重繪和最小化後的背景輪詢；完善驗證取消、失敗及退出時的資源清理，並清除舊前端、舊控制項和失去呼叫端的文案。

## 使用說明

- 發行套件為 x86_64 Linux AppImage，內建 .NET 和 Electron。既有設定可繼續使用；首次執行新版會更新 Steam 和應用程式選單的固定啟動入口。
- 憑證繼續依區服以明文儲存在本機，不新增加密儲存。
- 本次未加入遊戲個人設定檔遷移或備份功能。
- 沿用已經驗證的第三方執行元件，不隨本次介面升級一併更新。
