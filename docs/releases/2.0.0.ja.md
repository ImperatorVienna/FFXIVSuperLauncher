# FFXIV Super Launcher 2.0.0

2.0.0 では、1.0.0 の旧画面を新しい Electron グラフィカルインターフェースに置き換えました。引き続き Linux 上の中国版、繁体字中国語版、グローバル版クライアントに対応します。

## 追加と改善

- GenRyu と Cinzel フォントを採用した新しいダークインターフェースで、ボタン、ドロップダウン、スクロールバー、背景をぼかした透明なダイアログのデザインを統一しました。簡体字中国語、繁体字中国語、日本語、English を再起動せず即座に切り替えられます。
- ログイン認証を「ゲームを開始」の下に集約しました。中国版の QR コード認証、認証コードの手動入力、繁体字中国語版の Web 認証を含みます。ログはユーザーが手動で展開するスクロール可能なオーバーレイに変更し、選択とコピーに対応しました。すべてのページに診断ログの保存先の完全なパスを表示します。
- 独立したサードパーティーのプラグインリポジトリ管理を追加しました。追加、編集、有効化/無効化、削除、接続確認、ゲームリージョン間の同期に対応します。接続結果は対応するリポジトリの下に表示します。
- 従来の「Dalamud 設定を同期」を「外部リポジトリを同期」に置き換えました。サードパーティーのリポジトリ一覧と有効状態のみを同期し、同期先のメインリポジトリ、同梱リポジトリの有効設定、その他の Dalamud 設定を必ず保持します。同期元のリージョンを同時に同期先には選択できず、同期前にバックアップを保持します。
- プラグインの有効状態、表示言語、グローバル版クライアントの言語など、個別の設定を即時保存に変更しました。プラグインの有効状態とクライアント言語は次回のゲーム起動時に反映されます。ログイン認証情報は引き続き、各項目を入力した後にまとめて保存します。
- 「このアプリについて」に、既定で有効な「更新を自動確認」スイッチを追加しました。初期設定完了後に安定版を自動確認し、その後はユーザーが無効にできます。手動確認は引き続き利用できます。旧バージョンの AppImage を実行すると以前のバージョンに戻せます。戻した後は更新の自動確認を無効にしてください。
- 「このアプリについて」に「アート素材の出典」一覧を追加し、アイコン、GenRyu、Cinzel の出典リンクをまとめました。配布パッケージにはフォントのライセンスと出典記録を同梱しています。

## 修正と安定性

- 繁体字中国語版の Web 認証が進まなくなる問題と、キャンセルや終了後に認証プロセスが残り、再起動を妨げる問題を修正しました。
- 中国版の同梱プラグインリポジトリと、同名プラグインの異なる API バージョンが更新確認に影響する問題を修正しました。
- ゲーム終了後もプラグインとリポジトリが編集不可と判定される問題を修正しました。実行中のゲームやプラグインとの競合を防ぐため、ゲームの実行中はプラグイン、リポジトリ、クライアント言語、パス、互換性環境の変更を禁止します。
- プラグインとリポジトリで操作結果とエラーを個別に表示し、それぞれの状態を再読み込みするとメッセージを消去します。重複したエラー報告、誤った場所へのメッセージ表示、両側の再読み込みが互いを無効にする問題を修正しました。
- 保存結果とその後の再読み込みを分離しました。保存済みでも再読み込みに失敗した場合は、その旨を明示し、保存失敗と誤って報告しないようにしました。初期設定完了後に認証情報の読み取りに失敗しても、メイン画面への復帰を妨げません。
- Proton/Steam 環境の検索を、独立した時間制限付きの読み取りに変更しました。検索がタイムアウトしても、バックエンド全体を直接終了しません。書き込み操作のタイムアウト保護は維持し、結果が不確かな書き込みは自動再試行しません。Dalamud のネットワークタイムアウトとローカルバージョンへのフォールバック機構は変更していません。
- 変化がない場合の画面再描画と、最小化中のバックグラウンドポーリングを削減しました。認証のキャンセル、失敗、終了時のリソース解放を改善し、旧フロントエンド、旧コントロール、呼び出し元がなくなった文言を削除しました。

## 使用上の説明

- 配布パッケージは .NET と Electron を内蔵した x86_64 Linux AppImage です。既存の設定を引き続き使用できます。新バージョンの初回起動時に、Steam とアプリケーションメニューの固定起動入口を更新します。
- 認証情報は引き続きゲームリージョンごとにローカルへ平文で保存し、暗号化保存は追加していません。
- 今回はゲームの個人設定ファイルの移行やバックアップ機能を追加していません。
- 検証済みのサードパーティー実行コンポーネントを引き続き使用し、今回のインターフェース更新に合わせた更新は行いません。
