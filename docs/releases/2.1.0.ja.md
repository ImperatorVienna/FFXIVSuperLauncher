# FFXIV Super Launcher 2.1.0

2.1.0 は中国版のゲーム内データセンタートラベルを改善し、認証復旧とストレージのクリーンアップを追加するとともに、Proton 環境でのバックエンドのセッション管理を改善します。

## 新機能と改善

- DCTravelerX（[Dalamud-DailyRoutines/DCTraveler](https://github.com/Dalamud-DailyRoutines/DCTraveler)）との通信に対応しました。本ランチャーから中国版を起動すると、プラグインからデータセンター情報の取得とトラベルサービスの呼び出しができます。
- ゲーム起動後にフロントエンドを自動で閉じ、リソース使用量を削減します。バックエンドはゲームセッション、トラベル認証、Steam のゲーム実行状態を維持します。ランチャーを再度開くとフロントエンドを利用できます。
- トラベル認証の期限切れ時は、保存済みのクイックログイン認証情報による復旧を優先します。QR 認証が必要な場合もゲームを終了せず、ランチャーを再度開いて現在のゲームアカウントでスキャンできます。「ゲーム内 DC トラベルを再認証」ボタンはトラベルボタンの下にあります。復旧後はゲーム内で再操作してください。
- 「このアプリについて」にストレージのクリーンアップを追加しました。ダウンロードキャッシュ、ログ、内蔵ブラウザーのキャッシュを削除できます。ブラウザーの Cookie と認証状態は保持し、Dalamud 自身が管理するキャッシュとログには介入しません。
- 起動時に、失効を確認できたトラベルセッション記録と既知の一時ファイルを回収します。活動中のセッションや安全性を確認できない記録は保持します。
- 新しいボタン、説明、認証メッセージ、削除結果について、简体中文、繁體中文、日本語、English の翻訳を補完しました。

## 修正と安定性

- ゲームプロセス、Proton 環境、バックエンドセッションの識別を改善しました。操作に応じて使用状況を判断し、無関係なバックグラウンドプロセスによる誤ったブロックを減らします。
- ダウンロード、インストール、ダウンロードキャッシュの削除で共通のプロセス間ロックを使用し、確認後に別の処理がキャッシュへの書き込みを始める競合を防ぎます。
- 現在のログはログモジュールを介して処理します。他の活動中のプロセスが使用しているファイルや安全に処理できないファイルは、スキップとして表示します。
- トラベル認証のキャンセル、タイムアウト、初期化失敗、終了時のリソース解放を改善しました。バックエンドの QR 認証待機は最大 5 分です。
- 残存記録によって有効なセッションが見落とされる問題と、一部の用語置換によって翻訳が一致しなくなる問題を修正しました。

## 利用上の注意

- 配布形式は引き続き x86_64 Linux AppImage で、.NET と Electron を同梱します。既存の設定と認証情報を利用できます。
- ゲーム内トラベル対応の対象は DCTravelerX です。ottercorp DcTraveler や他のプラグインの互換性を保証するものではありません。中国版 Dalamud を有効にし、互換性のあるプラグインをインストールしてください。
- 画面が閉じた後もバックエンドプロセスは終了しないでください。トラベル申請の結果が不明な場合は、先に公式の申請状況を確認してください。ランチャーは自動で再送しません。
- ゲーム実行中もクリーンアップできます。ダウンロード・インストール中はダウンロードキャッシュを、操作・Web 認証中はブラウザーキャッシュを削除できません。削除数が 0 でも異常ではありません。
- 旧版の独立した認証ブラウザーの残存ディレクトリは対象外です。認証情報、ゲーム設定、インストール済みコンポーネント、バックアップはダウンロードキャッシュとして削除しません。
