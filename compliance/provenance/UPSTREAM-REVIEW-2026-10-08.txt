一、Steam 原生库
已检索 ValveSoftware 官方 GitHub 仓库清单和 Source SDK 原生库。
官方 source-sdk-2013 的 src/lib/public/linux64/libsteam_api.so 与当前包的
libsteam_api64.so 哈希不同；不能靠改文件名或保留库存在事实，声称精确来源已证实。
Source SDK 自有许可证带免费分发等条件，不是 MIT/GPL，不能套用到所有 Valve 库。

另找到 Valve Steamworks SDK Access Agreement：
https://partner.steamgames.com/documentation/sdk_access_agreement/
其中 1.1(b) 明确允许按协议将 redistributable_bin 内容与被许可软件一并分发。
因此不是“Valve 没有任何再分发许可”，而是“有条件的 SDK 授权，非开源许可”。
仍需确认现有二进制的准确 SDK 出处及与项目 GPL 分发的适用依据。所检视 XL 许可
没有额外 Steamworks 链接例外，不能自行代表上游添加。没有替用户接受协议或联系 Valve。
机器可核查记录：steam-native.json。
