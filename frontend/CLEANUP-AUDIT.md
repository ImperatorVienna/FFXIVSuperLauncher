# Electron 分支清理与功能对应

范围：当前开发分支；基于用户已确认繁中区能够登录、启动游戏并正常退出的 1.1.1，检查旧前端残留及故障边界。未修改或重新发布 GitHub 正式包；历史运行包、用户真实配置和许可证来源记录均保留。

## 删除和合并

- 删除旧 MainWindow 及页面分文件、凭据面板、本地 OTP 窗口、传送窗口、按钮尺寸辅助类、Avalonia 本地化适配和旧 Program 入口。
- 删除 Avalonia 包引用和条件编译分支，移除后端中仅供旧窗口使用的嵌入图标。保留 Electron 和桌面入口使用的图标文件。
- 删除独立繁中验证码浏览器、远程调试连接及旧 profile 管理。验证码页面生成器仍为现有隔离视图提供页面；官方网页浏览器独立保留。
- 删除旧凭据草稿列表装载、显示状态字段、字符串展示方法及旧表单保存入口。当前凭据管理通过 FrontendAccounts → CredentialDraftStore → RegionCredentials 保存。
- 删除旧日志目标适配和无人订阅的变化事件；合并插件、环境检测、传送及启动器更新的前端任务发起流程。
- 后端四语言资源各移除 198 条已无生产代码引用的旧界面文案。Electron 的界面词表独立保留；后端继续提供认证、凭据及内置网页所需翻译。
- Linux 发行脚本调用同一 Electron 构建器。更新测试改为调用现行后台协议，移除已不存在的命令行更新入口。CI 加入前端路径和 Node.js 测试。

## 功能对应

| 界面功能 | 具名后台接口／所有者 | 失败与取消边界 |
| --- | --- | --- |
| 首次设置、语言、区服与客户端路径 | system.initialize、setup.complete、snapshot、preferences.update | 默认配置先创建；区域文件无法读取时保留原文件，不阻断其他区域或全局设置 |
| 凭据管理与首次账户引导 | accounts.list/read/save、FrontendAccounts | 区服隔离、编辑版本检查；密码和密钥仅在明确读取编辑器时返回 |
| 登录与游戏更新 | operations.start/poll/cancel/reply、FrontendGame、RegionLogin | 三端共用任务状态；QR、手机确认码、手动 OTP 共用验证区域；旧挑战不能提交 |
| 繁中网页验证 | captcha.page/reply/fail，仅 Electron 主进程调用 | 独立分区；限时初始化和验证；后台状态监督不依赖页面布局事件；取消、失败、完成均销毁视图 |
| 公告、活动、服务器状态和官方链接 | official.read/open、FrontendOfficial、OfficialBrowser | 独立请求和超时；远端无 Node/preload；中国区资讯不读取国际区配置 |
| Dalamud、插件状态、更新和所选目标同步 | plugins.read/sources/start、FrontendPlugins | 后端计划标识、配置版本检查及游戏运行互斥；列表错误不使其他页面停止刷新 |
| Proton、Steam 注册、共享／Steam pfx | compatibility.read/update/diagnose | 即时操作及实际状态回报；国际区配置损坏不阻断共用环境设置读取 |
| 中国区超域传送 | travel.start/close、FrontendTravel | 选择与确认标识约束；取消停止轮询；订单结果不明确时不重复提交 |
| “关于”、声明、菜单入口与更新 | about.read/open/notice、desktop.install、updates.read/open/install | 更新检查独立；安装共享冲突保护；提交完成后直接退出并由安装助手重启 |
| 窗口记忆、游戏后最小化和 Steam 跟踪 | window.save、主进程 placement、steam.attach | 最小化不覆盖记忆；关闭验证视图后才等待已运行游戏的跟踪生命周期 |
| 本地验证码工具 | otp-tool.js + Web Crypto | 不依赖后端、凭据文件或网络 |
| 日志展示、选择复制与完整路径 | log-view.js、操作日志、about.read | 保留文字节点及选择；所有页面显示路径；共享诊断文件但不强耦合业务服务 |

IPC 契约、.NET 路由和 preload 暴露的方法由自动测试对照。窗口管理和文件选择由主进程处理；验证码令牌接口不向本地渲染页面开放。

## 边界回归

覆盖初始化 CDP 命令不返回、直接关闭、先取消再关闭、验证码页面构建失败、令牌提交失败、提交后的网页进程崩溃、后台操作结束而页面不再发送事件、旧视图迟到回调、OTP 超时、终态迟到通知、主渲染页面崩溃、清理步骤抛错、后端退出及损坏区服配置。

页面模块的同步／异步异常不再中断其他模块的刷新；凭据列表读取失败仍允许首次设置与“关于”初始化。普通后台错误返回给当前调用；后台连接损坏会终止失效连接并关闭验证视图。完整 Electron 运行时崩溃仍属于整个界面的进程边界，不能声称任意故障都完全隔离。

Steam 模式在关闭界面后继续跟踪已经启动的游戏是既有行为；用户打开的官方网页窗口也是独立功能，不作为验证码残留进程强行结束。测试只操作隔离目录和受控子进程，不终止其他应用。

## 待复核／修正：错误传播与依赖（2026-10-11，静态审查，未改功能代码）

- [x] connection.js startManagedOperation 捕获异常先 fail 再抛出；plugins.js run 的调用方随后再 error，造成同一启动失败既进入通用反馈又进入插件／仓库反馈，重复记录。自动检查更新开关 apply(...,true) 也有两层报告。应明确错误展示归属。
- [x] 首次设置完成回调在关闭向导后 await reloadAccounts，再 navigate；凭据读取失败阻断回调后半段。setup.execute 此时 dialog 已移除，错误写进已关闭向导，外层 feature 包装只保护公开方法，不能覆盖此按钮事件内部的完成回调。应隔离已完成配置与凭据刷新失败。
- [x] 保存与刷新耦合：FrontendCompatibility.Update 写入后调用完整 Read（扫描 Proton／Steam）；FrontendAccounts.SaveAsync 写入且消耗 revision 后再 ListAsync；FrontendPreferences.Update 写入后 Snapshot。后续读取失败会将已写入的操作报告为失败，需区分持久化结果和展示刷新结果，不能笼统声称失败必然恢复旧配置。
- [x] plugins.js busy 同时包含插件和仓库 loading；加载任意一侧都禁用两侧，刷新 Promise.all 中也等待另一侧。读取失败已有分别 catch，不会直接把另一侧数据清空，但慢读取仍扩大等待范围。
- [x] 架构风险：FrontendHost 主循环串行执行同步文件扫描／凭据读取；BackendClient 任一请求超过 10 秒会关闭全部待处理请求并终止后端。这是防止超时后继续写入的现有保护，不能直接删掉；需将耗时只读发现改为有界异步任务，避免无关慢磁盘拖累登录／验证。普通业务异常已按请求返回，不等同于全局退出。

以上为代码路径审查，未模拟慢磁盘、凭据文件异常或真实登录，也未构建新包。后续修正需增加针对上述边界的回归用例。


### 本轮落实

上述清理及依赖项已处理。兼容环境扫描使用异步只读响应和单任务上限；不可取消的底层文件读取不会被伪装为已终止，原扫描退出前拒绝启动第二个扫描。写入仍受严格连接超时保护，断连后提示结果待核对，不自动重试。保存后的刷新错误分别回报，凭据编辑器刷新失败会清空输入并禁止继续保存，重新进入页面可重读。已增加真实后端慢扫描故障注入与无界面浏览器失败边界回归。

## 通用界面优化回归（2026-10-12）

- 以 2.1.0 为基线，仅实现常规鼠标／键盘界面优化，没有恢复手柄导航、模拟输入或 Steam 键盘代码。
- 首次设置分三步，复用语言／国际区默认设置；选择即时串行保存。路径草稿和错误独立保留，排队中的下一步不能越过保存失败，未保存输入不能完成配置。
- 自动更新提示继续等待首次设置完成，避免叠加弹窗；安装请求防重入，失败留在原窗口并允许重试。
- 页面值更新减少整体重建，插件／仓库分别判断渲染；普通焦点恢复共用 ui-state.js。共享方法不监听设备、不实现导航路径。
- 小窗口由页面滚动，登录验证、公告与登录卡不各设滚动区；弹窗、原生列表和日志保留受限的独立滚动。
- 删除旧两步向导文案和已失效的内部滚动／容器压缩样式，更新开发文档。兼容环境测试夹具按真实后端仅返回保存确认，避免用模拟列表掩盖问题。
